### 1.2 规划者已核对的事实（与任务说明一致的部分）
- Cu C1100，厚 0.5 mm 的薄片嵌在 1 mm 铝板中，**被辐照面是 0.5 mm × 15 mm 的抛光端面**（4000# 砂纸）；大气环境；1064 nm、60 ns、单脉冲；聚焦物镜 NA 0.14（5×）。
- 高通量 0.4 mJ / "22 µm" / 105 J/cm²；低通量 0.32 mJ / "31 µm" / 42 J/cm²。105 = E/[π(11 µm)²]、42 = E/[π(15.5 µm)²] 成立，即表中数值按直径用、通量为平顶平均。
- 成像：侧视，20× NA 0.4 物镜 + 带通滤光片（约 500 nm，带宽未给）+ 像增强器（Hamamatsu C10880-03C，门宽 10 ns，增益设置 960）+ 冷却 CCD（8 位）。每个时间点是不同脉冲。
- 图像处理：阈值 27 → 最大水平宽度的一半为"半径"；像素计数为面积；逐行旋转为体积；阈值 100/220 取上下边界（高通量与飞溅对比时用 40/80/120）。
- 冲击波（图 3d）：初速约 5400 m/s，后期约 550 m/s，约 800 µm @ 900–1000 ns，两种通量基本重合。飞溅上升速度 190 / 344 m/s。
- S12 的 COMSOL 模型只算熔池，不含羽流/等离子体/辐射；表 5 有单位错误（Lm=204、Lv=5069 应为 kJ/kg 量级）。

### 1.3 规划者新发现的问题（初测，M0 必须复核；这些直接影响方案）
1. **S4 的比例尺**：内嵌图中 400 µm 标尺长约 38 px → **约 10.5 µm/px**（不是 8）；S3 的标尺约 53 px → 约 7.5 µm/px。两图放大率不同。S4 每帧约 88×84 px（约 925×880 µm）。
2. **低通量半径自相矛盾**：图 2c 右图最大 236.5 µm，但其放大插图与图 S6 同一时刻只有约 165 µm（比值 0.70 ≈ 7.5/10.5，疑为两组标定系数混用）。正文图 2a 的"100 µm"标尺与 S3 的"400 µm"标尺相差约 2.2 倍。按 S3 标尺粗测 280 ns 半径约 200 µm，支持 236.5 µm 一组；因此"2500 m/s"初速可能被低估约 1/0.7。
3. **S7a 平均灰度峰值**出现在 0 ns 之后的第一个点（约 20 ns，约 91），不是正文说的 60 ns；后期平台约 22（低于阈值 27），说明"平均灰度"的统计区域定义与文字描述不完全一致，且**相机本底约 20 灰度**。
4. **高通量早期帧不可能是纯流体图像**：S7b 在 0 ns 已有半径约 180 µm、20 ns 约 235 µm 的发光区，而同时刻冲击波半径只有约 50–150 µm（图 3d）。发光区不可能跑到冲击波外面。0–30 ns 帧是"内部亮度较均匀、上缘平直、下缘圆弧"的 D 形，而同一光路下低通量 S3 的 10–35 ns 帧是边缘锐利的小圆斑。
   → **候选解释（均未证实，M0.6 逐一检验，不预设结论）**：
   - **H-blur（离焦）**：羽流自发光，按几何光学离焦后，每个物点成像为半径 r_b = Δ·tan(arcsin NA_eff) 的均匀圆盘（NA 0.4 时 0.436·Δ）。SI 写对焦在"铜样品靠相机一侧的前端"，光斑距该端面 Δ ≲ 250 µm，对应 r_b ≲ 110 µm；**单靠离焦解释 180–235 µm 的早期半径偏紧**，需与真实羽流尺寸叠加。平直边可能来自样品边缘遮挡部分光锥（渐晕/"猫眼"截断核）。
   - **H-t0（时间零点偏移）**：羽流成像与泵浦探测是两套触发，若 S4 的 0 ns 比激光到达晚 30–50 ns，尺寸矛盾可大部分消除。
   - **H-halo（像增强器光晕/饱和扩散）**：早期帧未饱和（灰度约 40–150），可能性较低，但需检查边缘轮廓。
   - 判别量：早期盘半径随时间是"跳到定值再缓慢增长"（H-blur）还是"从小到大连续增长"（H-t0）；边缘宽度；积分亮度；与 S3 的边缘梯度对比。
   - 无论哪个成立，都进入成像/时间模型（§2.6、§5.1）作为待定仪器参数；**最直接的解决办法是向原作者询问对焦位置、光斑在端面上的位置及时间零点定义。**
5. **低通量凹坑**（图 5b）直径约 28 µm，支持"表中 31 µm 是 1/e² 直径"而非半径（按 Liu D² 法估算）。
6. **滤光片通带包含 515 nm**：SI 写羽流成像与泵浦探测"使用同一滤光片"，而探测光是 515 nm。因此 Cu I 515.32 nm 必在带内，510.55/521.82 nm 是否在带内取决于带宽。
7. **冲击波能量估计**（Sedov–Taylor，半球）：约 0.06–0.13 mJ，即脉冲能量的 15–40% 进入气体。靶面直接吸收只有百分之几到十几，说明**能量收支由等离子体吸收主导**，这是模型必须重现的首要定量门槛。
8. 其他：面积峰值正文 0.0296 mm² 对图 0.27 mm²（图为准，π·317² ≈ 0.32 mm² 自洽）；低通量面积正文 0.0168 对图 0.168 mm²；表 3 探测光波长写 1030 nm（实为倍频 515 nm）。

## 2. 物理模型（决策与依据）

### 2.1 工况量级
- 峰值功率约 6.3 kW（高）/ 5.0 kW（低）。若 w（1/e² 半径）= 11 µm：峰值强度约 3.3 GW/cm²、峰值通量约 210 J/cm²；若 w = 22 µm：约 0.83 GW/cm²、53 J/cm²。低通量对应 1.4 / 0.35 GW/cm²。
- 两种读法都远高于 Cu 在 1064 nm 纳秒脉冲下的等离子体点燃阈值（10⁸ W/cm² 量级）→ 强等离子体屏蔽区，靶面温度可接近临界温度。
- 冲击波后期马赫数约 1.6，背压不可忽略；羽流发光区最大约 300 µm，寿命约 600–1000 ns。

### 2.2 包含的过程（基线模型）

| 过程 | 处理方式 | 依据 |
|---|---|---|
| 靶材加热/熔化 | 2D 轴对称焓法热传导（z 向隐式、r 向显式），物性随温度变化；表面后退以对流项计入 | 60 ns 内热扩散长度约 5 µm，与光斑半径 11–15 µm 可比，径向导热不可省 |
| 表面吸收率 | A(T)：Drude 模型（由电阻率 ρ_el(T) 得碰撞频率）× 表面状态因子 f_A | 抛光 Cu 在 1064 nm 室温吸收约 3–5%，液态升至约 10–30%；砂纸抛光面偏高，f_A 为标定参数 |
| 蒸发/回凝 | Knight (1979) Knudsen 层跳跃条件，与相邻气体单元的马赫数耦合；背压下可回凝；饱和蒸气压用 Clausius–Clapeyron，L_v(T) 用 Watson 关系在 T_c 处归零 | 纳秒烧蚀建模的标准做法 |
| 近临界区 | 表面温度封顶 0.9 T_c（T_c 取 7800 K，不确定度 ±600 K）；超出能量记入"爆炸沸腾标志"并统计 | 见 §2.4 |
| 气相流动 | 可压缩 Navier–Stokes，轴对称；Cu 质量分数 Y 输运 | 冲击波 + 接触面 + 背压 |
| 粘性/导热/组分扩散 | 全部包含，输运系数查表；组分扩散取 Le=1 | 1 atm、10⁴ K 时 ν≈7×10⁻³ m²/s，Re≈15；导热长度约 30 µm/100 ns、扩散长度约 50 µm/500 ns，相对 300 µm 羽流不可忽略。**物理耗散使解对网格收敛**（否则接触面失稳由数值粘性决定） |
| 状态方程 | LTE 化学平衡：N₂/O₂/NO/N/O/Ar 及其离子（到 +4）、Cu 到 Cu³⁺、电子；Debye–Hückel 电离能下降；表格 p,T,nₑ = f(ρ,e,Y) | 1 atm 以上、T>8000 K 时满足 McWhirter 判据；电子–离子弛豫约 1–4 ns ≪ 观测时间 |
| 激光在气相中的吸收 | 逆轫致（电子–离子含 Gaunt 因子、电子–中性）+ 激发态光电离（Kramers 近似），含受激发射修正；高斯光束射线管（w₀、M²），到靶面按 1−A 反射后回程再吸收一次 | 等离子体屏蔽主导能量收支（§1.3 第 7 条）；瑞利长度约 240–360 µm，与羽流高度同量级，光束发散必须计入 |
| 辐射冷却 | 净发射系数 NEC(T,p,Y,R_p) 体积能量汇；R_p 基线 100 µm | 连续谱光学薄、强线自吸收；p 约 100 atm 的前 100 ns 内冷却时间约 0.1–10 µs，不可省但不主导 |

### 2.4 相爆炸
决策：**基线不建模相爆炸的两相喷射**，只做 0.9 T_c 封顶并记录超限能量。理由：(1) 羽流能量主要来自等离子体吸收而非蒸气焓；(2) 两相喷射缺乏可约束的参数。作为模型形式不确定度，做一个敏感性情景：把超限能量按 0.9 T_c 饱和蒸气的焓折算成额外蒸气质量注入。两种情景的指标差异计入不确定度。

### 2.5 控制方程（供 Claude 实现时对照）
气相（z>0）：
```
∂ρ/∂t + ∇·(ρu) = 0
∂(ρY)/∂t + ∇·(ρYu) = ∇·(ρD∇Y)
∂(ρu)/∂t + ∇·(ρuu + pI) = ∇·τ
∂E/∂t + ∇·((E+p)u) = ∇·(κ∇T) + ∇·(τ·u) + ∇·(ρD (h_Cu − h_air) ∇Y) + Q_las − Q_rad
p, T, nₑ = EOS(ρ, e, Y)          Q_rad = 4π·NEC(T, p, Y, R_p)
dI/ds = −α₁₀₆₄(ρ,T,Y)·I  沿高斯光束射线管，Q_las = α·(I_in + I_refl)
```
靶材（z<0）：`∂H/∂t − v_rec ∂H/∂z = ∇·(k∇T)`；表面：`−k ∂T/∂z = A(T_s)·I_s − ṁ·L_v(T_s) + q_gas`，ṁ 由 Knudsen 层关系给出，并作为气相底边界的质量/动量/能量通量。
边界：r=0 对称轴；z=0 为靶面（光斑外为无滑移等温壁）；外边界无反射出流。初始：1 atm、300 K 空气。

### 2.6 发光与成像正演模型（后处理，决定"像不像 S4"）
1. **光谱发射/吸收系数** j_λ、κ_λ（480–540 nm，约 1000 个波长点）：
   - 谱线：NIST ASD 的 Cu I（510.55、515.32、521.82 nm 等）、Cu II（490–510 nm 一组）、N II（500.1–500.5 nm）、N I、O I、O II；能级布居按 Boltzmann，线型 Voigt（Stark + Doppler），Stark 宽度取文献值，缺失时用 nₑ 标度并做 ×/÷3 敏感性。
   - 连续谱：自由–自由 + 自由–束缚（Kramers–Unsöld，Biberman 因子）+ 电子–中性轫致。
   - κ_λ = j_λ / B_λ(T)（Kirchhoff）。
2. **视线积分**：轴对称场沿视线 y 做带自吸收的辐射输运（前向 Abel 投影）。
3. **离焦模糊**：把视线方向分层，每层的贡献与半径 R_k = |y_k − y_f|·tan(arcsin NA_eff) 的圆盘核卷积（NA_eff ≤ 0.4，tan = 0.436）；y_f（对焦面相对光轴的位置）是**每个实验系列各自的仪器参数**。可选项：靶面以下光线被样品遮挡的"截断核"。
4. **时间门**：10 ns 门内平均（场量每 2 ns 输出一次）。
5. **探测器**：`counts = clip(round(B + G·∫T_f(λ)·L_λ dλ), 0, 255)`。B 从实验帧角落直接量（约 20），G 为每系列一个标量，T_f 为滤光片情景（§5.1）。
6. **降采样与伪彩**：重采样到 10.5 µm/px（S4）或 7.5 µm/px（S3），套 matplotlib `jet`（0–255）出图；指标在未加噪的灰度图上计算。
7. **图像指标流水线**（与 SI S2 逐条对应）：阈值 27 → 半径/面积/体积/平均灰度；阈值 100/220（及 80）→ 上下边界。另加三类**对模糊不敏感**的指标：总亮度 Σ(I−B)（模糊守恒）、亮度质心高度 z_c(t)、二阶矩 σ_x²(t)、σ_z²(t)（恒定模糊只加一个常数，取差值即消除）。

## 3. 数值方法与软件路线

### 3.1 路线决策：自写 `lipsim`（Python + Numba），不基于现成框架
- 本问题的专用部分（两元素 LTE 表格 EOS、Knudsen 边界、靶材耦合、光束吸收、发光成像）在任何框架里都要自己写；框架只贡献约 500 行的有限体积流体核，这恰是最容易写、最容易验证的部分。
- FLASH（需申请许可、仅 Linux）、Castro/PeleC（AMReX，需 WSL2，自定义 EOS/边界的远程调试成本高）、PLUTO（混合物 EOS 需改内核）、OpenFOAM（强激波 + 表格 EOS 鲁棒性差）都会让"Claude 写代码—Codex 在 Windows 上跑"的往返次数显著增加。
- Python + Numba：云端 Linux 与工作站 Windows 是同一份代码，`pip` 即装，无编译器、无 WSL2、无管理员权限；每个物理模块可直接 pytest。性能约为 C 的 0.5–1 倍，对本问题规模足够（§3.4）。
- 编码约束（便于日后必要时移植到 C++）：热点内核全部写成对数组的显式循环 `@njit(parallel=True, fastmath=False)` 纯函数，不用类、不用 Python 对象。
- 论文中表述为"in-house 2D axisymmetric finite-volume code"，随文开源（Zenodo DOI），以完整验证套件支撑可信度。

### 3.2 离散与时间推进
- 有限体积，结构化 r–z 拉伸网格；MUSCL（原始变量 ρ,u,p,Y 重构，van Leer 限制器）+ HLLC；SSP-RK2；轴对称几何源项按面积加权有限体积形式处理。
- 算子分裂（每步）：流体 → 扩散类项（粘性/导热/组分扩散，RKL2 超时间步）→ 源项（激光射线积分、NEC；带能量限制器的子循环）→ 靶材（z 向三对角隐式）→ 更新 Knudsen 边界。
- 表格 EOS：(log ρ, log e, Y) 三线性插值；ρ 10⁻⁴–10³ kg/m³，T 300–1.5×10⁵ K，Y 取 13 个非均匀节点。两种气体接触面处的压力振荡用验证算例 V5 量化，若 >1% 改用 double-flux 准守恒格式。
- 重启：每 20 ns 模拟时间写一次检查点；能量/质量收支每步累计并写日志。

### 3.3 计算域与网格

| 网格 | Δr 最小 | Δz 最小（壁面） | 单元数 | 用途 |
|---|---|---|---|---|
| G0 粗 | 2 µm | 0.5 µm | 约 7.6×10⁴ | 系综（敏感性、标定） |
| G1 生产 | 1 µm（r<200 µm） | 0.25 µm，26 µm 内过渡到 1 µm | 约 3.0×10⁵（约 471×642） | 正式结果 |
| G2 细 | 0.5 µm | 0.125 µm | 约 1.2×10⁶ | 网格收敛 |

- 计算域 r∈[0, 1.2 mm]、z∈[0, 1.5 mm]；远场单元上限 4 µm（保证 800 µm 处冲击波位置误差 <2%）。
- 靶材网格：z 向 300 层，从 10 nm 几何增长覆盖 40 µm；r 向与气相在 r<100 µm 内共用。
- 时间步：早期最大波速约 2×10⁴ m/s → Δt≈10⁻¹¹ s；脉冲后波速降到约 1.5 km/s。G1 全程（0–800 ns）约 3×10⁴ 步。

### 3.4 耗时与算力预算
- 假设 Numba 内核约 0.3 M 单元·阶段/秒/核（M2 基准卡必须实测，低于 0.2 M 则先做性能优化再往下走）。
- G1：约 1.8×10¹⁰ 次更新 ≈ 17 核时 → 16 线程约 1–3 h。G0 约 15 min（8 线程）。G2 约 8–14 h（32 线程）。
- 并行策略：**单算例 8–16 线程，多算例并发**（实测 64 物理核 / 128 逻辑核、2 个 NUMA 节点，可同时跑 4–8 个）。这样回避 Windows 上超过 64 逻辑核的处理器组问题，系综天然并行。超线程不计入。
- 总预算：粗网格系综约 310 例 ≈ 1200 核时；生产算例约 80 例 ≈ 1900 核时；收敛研究约 600 核时；合计约 4000 核时，满载约 53 h，含返工按 **1–2 周机时**计。
- 存储：完整场（每 2 ns、float32、压缩）约 1–2 GB/例，只保留生产算例；系综每例只留合成图像和指标（约 1 MB，留在工作站），入库的是汇总表。预留 300 GB。

- 长任务一律用已有的 `scripts/win/job.ps1 start` 后台启动；任何算例可从检查点续算。工作站需关闭自动休眠（属系统设置，由用户操作一次）。

### 5.2 标定/盲预测划分
- **训练集（仅低通量）**：图 2b/2c、S5、S6、图 4a/4d1 的羽流指标 + 低通量冲击波轨迹 + 图 5b 凹坑直径。
- **测试集（高通量，盲）**：S4 全部帧、S7a–d、图 4e1/S12b 羽流下边界、高通量冲击波轨迹。
- 高通量允许使用的信息仅限两个预先声明的仪器锚点（G_high、y_f,high），其余物理参数一律从低通量后验继承。同时报告"假设 G_high = G_low、y_f,high = y_f,low"时的结果，作为对仪器假设的检验。
- **预注册**：标定协议、指标定义、通过标准、情景列表写入 `docs/PREREG.md`，在运行任何高通量生产算例之前提交；此后不得修改，只能追加"偏离记录"。
- **失败预案（同样预先写明）**：若盲预测未达标，如实报告盲预测结果，然后做两通量联合再标定 + 留一指标交叉验证，论文中两者都给出。
- 低通量数据的尺度矛盾（§1.3 第 2 条）：以 M0 从 S3/图 2a 帧按 S3 标尺重测的结果为准；若无法判定，两种尺度各标定一次，高通量预测带取并集。

### 5.3 敏感性与 UQ 流程（全部在 G0 粗网格上做系综）
1. Morris 筛选：约 10 个参数 × 10 条轨迹 = 110 例，对每个指标排序，留下前 4–5 个。
2. 拉丁超立方 200 例（低通量）→ 对标量指标建高斯过程代理模型（scikit-learn），留出 20% 检验代理精度（R² >0.9）。
3. 贝叶斯标定（emcee 在代理模型上采样）；似然中的方差 = 实验散度² + 数据提取不确定度² + 模型差异项（取指标的 10%）。
4. 后验预测：抽 30 组后验参数，在 G1 上跑高通量 → 指标的中位数与 5–95% 带；G0→G1 的系统偏差用 3 个配对算例修正。
5. 模型形式情景（§5.1 最后一行）各跑 1–2 例，差异以独立误差条给出。

## 9. 风险、应对与可诚实声明的局限

| 风险 | 可能性 | 应对 |
|---|---|---|
| 实验元数据缺失导致仪器参数与物理参数简并（模糊 ↔ 真实尺寸，增益 ↔ 温度） | 高 | 向作者要原始数据（§11 第 1 项）；用模糊不敏感指标；仪器参数只用预先声明的最少数据锚定 |
| LTE 低估后期（>400 ns）亮度，羽流"消失"过早 | 中–高 | 输出 LTE 有效性诊断；论文明确说明；不为凑后期亮度而调物理参数 |
| 低通量与高通量成像条件不同，盲预测的亮度/尺寸失败 | 中 | 预注册的失败预案；同时报告两种仪器假设 |
| Numba 性能或 Windows 多核调度不达标 | 低–中 | M0.2/M2.7 两次基准把关；多算例并发；最后手段是热点内核移植到 C |
| 表格 EOS 在两气体接触面产生压力振荡 | 中 | V5 量化；备用 double-flux 格式 |
| 早期近壁薄层刚性（0.25 µm 单元 + 强源项）导致时间步过小 | 中 | 源项子循环 + 能量限制器；脉冲结束后可重映射到较粗近壁网格 |
| 近临界靶面物理（相爆炸）主导蒸气量 | 中 | 情景对比入不确定度；不宣称预测烧蚀质量 |
| 执行往返过多、额度超支 | 中 | §7 省额度规则；里程碑门；每张卡验收标准可机检 |

**论文中应诚实声明的局限**：(1) 单温 LTE、平衡化学；(2) 不含熔体飞溅、微滴、纳米颗粒及其炽热辐射；(3) 相爆炸未显式建模；(4) 轴对称近似，未计样品端面有限宽度的 3D 效应；(5) 辐射冷却用净发射系数近似；(6) 实验图像只有低分辨率伪彩 JPEG、每帧不同脉冲、无绝对辐射定标，滤光片带宽/时间零点/离焦量/增益为推断量；(7) 比较是统计指标层面的半定量一致，不是逐像素复现；(8) 原论文数据存在若干内部不一致（§1.3），本文采用值及理由在补充材料中列出。

## 11. 需要用户拍板或提供的事项
1. **能否从原作者处取得**：S3/S4 原始 8 位图像（或更高分辨率版本）、相机像素尺寸与靶面在图中的位置、滤光片型号/带宽、脉冲波形与时间零点定义、光斑尺寸的测量方法与 M²、两组实验的增益/衰减片/对焦是否相同。拿到任何一项都能直接消掉一个推断参数。拿不到则按本规划的推断方案进行，并在论文中声明。
2. **确认软件路线**：自写 Python + Numba 代码、原生 Windows 运行、随论文开源。若期刊或合作者要求必须用某个现成软件，需现在说明（会明显增加工作量）。
3. **确认验证逻辑**：低通量标定 → 高通量盲预测；盲预测不达标时如实报告并再标定。论文结论定位为"指标层面的半定量一致 + 不确定度带"。
4. **确认范围**：不模拟飞溅/纳米颗粒/3D 边缘效应（列为局限）。若必须包含其中某项，工期至少增加 3–4 周。
5. **确认资源**：工作站独占约 1–2 周机时、约 300 GB 磁盘；允许用户级安装 Miniforge；PyPI/conda 是否需要走镜像。
6. **M4 门的参与方式**：M4 评审是唯一建议用户亲自看一眼的节点（约 15 分钟，看 4 张图），其余节点可全自动推进。
