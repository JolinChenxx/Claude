# S4对照图合同

科学问题：已验证LTE守恒框架在指定高能输入下，能否同时解释发光羽流的快速增强、扩展及后期消退？证据以实验一致的可见发光及尺寸时序为主，铜元素/温度/ne为解释性配图，不替代相机观测量。

Python/matplotlib为本任务已建立后端。图形采用quantitative grid与image plate+quant；S4实验/仿真逐时刻同尺度，统一亮度响应。实验伪彩来自原图，可逆映射误差显式记录，不补造原始CCD灰度。数值场仅从实际保存解读取，时间内积分可插值但须记录，不能虚构新求解。

早期0–80ns标定一个全局gain和一个固定offset，后期150–740ns用于留出验证，不逐帧归一化。所有对照共用gain、offset、background、阈值和空间响应。随机误差条不适用；数值/输入/图像重建敏感性单列。

演化曲线与物理场图约183mm宽，九时刻对照板267mm宽以容纳同尺度图像，字体至少5pt，导出PDF/SVG/300dpi PNG；动画真实物理时刻注记。所有最终多面板保存实际绘图区对齐JSON，运行PDF字号和碰撞审计后逐面板视觉检查。
