# 原LTE守恒方程的ALE变换

保留原柱坐标轴对称守恒量q=(ρ,ρu_r,ρu_z,E,ρY_Cu)及原LTE闭合，不把场图事后平移当成ALE求解。所有新例在独立MPH中。

参考坐标(R,Z)，物理坐标r=R、z=Z−s(R,Z,t)。网格位移s在铜气界面等于真实累计退缩d(R,t)，外边界为零，对称轴为自然对称边界。形变梯度F=[[1,0],[−s_R,1−s_Z]]，体积雅可比J=1−s_Z，网格速度w_z=−s_t。r不变，所以轴对称体积权重2πr不另变。

Euler通量(F_r,F_z)在参考域中的保守Piola通量为(J F_r, s_R F_r+F_z−w_z q)。原式变为：

`∂t(J q) + (1/R) ∂R(R J F_r) + ∂Z(s_R F_r + F_z − w_z q) = J S`。

COMSOL通用PDE以`da=axisWeight*J`和`f=axisWeight*(J*S−J_t*q)`实现乘积导数，不能遗漏J_t q。原柱坐标径向压强几何源同步乘J。物理梯度为∂r=∂R+(s_R/J)∂Z、∂z=(1/J)∂Z；数值扩散、热传导均使用物理梯度。固体焓方程同样使用J及网格速度的能量通量。激光准静态通量无储存，但吸收体源乘J；入射和反射光沿物理竖直线穿过羽流。

界面弧长伸缩为A_s=sqrt(1+d_R²)，指向气体的法向N=(d_R,1)/A_s，真实法向退缩速度v_n=−mdot/ρ_Cu，竖直高度演化d_t=A_s mdot/ρ_Cu。净通量mdot=正向蒸发−铜原子回流，可以为负，未人为截断凝结。所有净铜质量、气体总质量、动量和焓交换同步扣加。

气体界面相对通量能量除原注入/返回焓外，含压力功p w·N=−p mdot/ρ_Cu；固体收到相反项。两个域的界面源相加只剩真实靶面吸收光能。保留原模型Knudsen注入速度和中性蒸气焓闭合；未把该边界提升为完整Knudsen层动力学，也未引入非平衡电离。

独立检查包含：J在两个域所有保存时刻为正；气体实际体积增量与∫2πR d(R,t)dR相符；总气体质量、铜质量、全系统能量含外边界通量闭合；几何恒等式J_t=∂Z w_z只作为实现一致性，不把代数恒等式单独宣称为数值验证。局部峰值、FE网格和最大时间步需另做对照。

实现中的重要纠正已留痕：边界1是铜靶对称轴，2才是底边，3是气体轴，4为铜气界面，5顶部，6/7侧边。错误固定轴线的旧ALE解全部作诊断；正式配置固定2/5/6/7，对称轴1/3不固定竖直位移。
