# 可复核的LTE发光与S4相机近似

只使用保存的真实LTE场。相机亮度不是铜质量分数、电子密度或温度的直接伪彩。源数据为`data/*_visible_lines.tsv`，来源NIST ASD，完整请求地址在同名.url。铜重点线510.5541、515.3235、521.8202 nm均保留；也包含有跃迁概率、上态低于电离阈值的其他Cu I/II、N I/II、O I/II线。无A值的线不补造。

每条线以EOS原有限配分函数计算Boltzmann上态布居，jν=hν A n_u φν/(4π)。标准干空气波长按Peck–Reeder折射率转真空频率。热Doppler与自然宽度用pseudo-Voigt近似，含径向流速在视线上的Doppler投影；未拟合Stark宽度。LTE吸收取αν=jν/Bν，满足Kirchhoff及受激辐射修正。ν≈常数的孤立线处理沿波长保留其Doppler带宽。未包含自由束缚连续谱、分子带和碰撞展宽，这些限制会影响最终模型解释能力。

连续谱保留原LTE模型free-free总发射系数1.426e−40 sqrt(T) ne ΣZ²ni W/m³，以h/(kT) exp(−hν/kT)归一化至频率。源函数和吸收同样满足LTE关系。可见能量用所有未衰减体发射积分作为逃逸辐射上界；若该上界已远小于吸收能量5%，就能排除触发反馈门槛。若上界超过5%，需进一步算实际净逃逸/吸收及反馈，不能直接忽略。

轴对称视线使用r=sqrt(x²+y²)，逐小段精确形式I_out=I_in exp(−αΔs)+(j/α)(1−exp(−αΔs))。光薄极限用稳定展开式。只有线中心总光深上界<0.005的射线走光薄快速路径；其余做分辨热谱宽的频率积分，不把大光深当作光薄。逐通带保留99.99%发射功率对应谱线，报告截断上界，不能按全宽带排名丢弃弱窄带谱线。

ALE场导出同时给出物理z与J，在每个半径上反变换到物理坐标再插值视线。COMSOL插值的维度表达式可能自动以μm输出，导出器用zPhysical/1[m]强制SI。场网格的0.5–5 μm采样是后处理插值网格，不替代有限元尺寸验证。

主通带475–525 nm，敏感性490–510和450–550 nm；每个通带都做相同输运。相机采样11.111 μm/像素，主PSF为1像素FWHM，敏感性0和2像素；10 ns门宽对保存时间节点的分段线性辐亮度精确梯形积分。只求统一线性增益、统一背景、0–255饱和响应。背景从实验角落固定估计，不逐帧改变。0–80 ns早期排序像素亮度分布确定一个全局gain和60–120 ns（2 ns步距）的固定时移；排序用于避免把未标示的实验靶面位置当成额外自由空间平移。增益遍历饱和断点之间的全部分段二次目标，取g≥0的全局最小值；原先loggain±18的任意边界已撤销，因为诊断H00触及了上限。已用解析无饱和、远超旧上限的饱和例子及独立稠密增益扫描验证。保留早期拟合误差；早期不是独立验证。150–740 ns全部保留作验证，不改变gain、offset、background。

另用论文NA=.4、透过率/QE=1、10ns、525nm将主通带物理辐亮度换算为理想收集光子量级，逐帧记录明亮掩模中低于1光子的比例。此诊断不增加拟合参数、不修改主相机响应；若极大数学gain照亮的是远低于1光子的LTE尾部，不能把均值灰度的表观吻合解释为真实单脉冲发光已被支持。完整单光子统计不在本轮计划内。

图像灰度是从出版JPEG和S2色条反演，不是CCD原始数据。主阈值27，另给100/220；3×3开闭及最大连通域在实验/仿真共用。标尺端点±1像素、颜色第二近邻和无开闭运算敏感性独立输出，不能伪造随机误差条。绝对上下亮边高度的实验原点尚未独立注册；半径、面积、时间消退为主要比较量。

实现验证：均匀平板光薄/厚解析式，LTE均匀Doppler谱线积分（已测相对差5.6e−5），视线几何镜像、10ns分段线性门积分与统一饱和响应。高光深、LTE物种/配分函数适用范围及图像标定误差在最终报告单列。

有限配分函数截断检查：Cu I全部109个阈下态相对原25态配分函数，在6000/7000 K分别增加约0.012%/0.076%，在10000 K约1.85%。因此6.191/6.192 eV可见线上态略超原0.8电离阈值截断并不等于其布居为零；本后处理沿用原配分函数，并披露截断影响，没有暗改EOS表。
