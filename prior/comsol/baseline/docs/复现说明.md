# 复现入口

本项目使用 COMSOL Multiphysics 6.2.0.290、Java API 和 Python 3.9。所有新计算均位于独立S4项目；保留的11月2日LTE基线文件的SHA256为`0C73727387DDAAB9EAF8999C92EE5BB2D39447250605E715F62577E7B350D8D2`。不依赖未通过的非平衡升级。

先查看根目录`delivery_state.json`和`status.json`。存在正在运行的worker/driver时，不另启求解。`solver_budget.json`累计本轮全部实际重求解耗时；程序限制累计14400秒、每段2700秒，使用COMSOL官方保存停止。新一轮预算须另行明确，不在复现程序中隐式清零。

## 从保留基线重新构建

在项目目录中运行以下命令。工况名须为未使用的新名称，程序不覆盖既有模型。

```powershell
python work/reproduce.py build REPRO --mesh 1 --step '0.5[ns]'
python work/reproduce.py solve REPRO --threads 8
```

`build`先配置400μJ入射、双程羽流光学与铜表面吸收，再建立净蒸发和守恒ALE。保留原LTE表、气体守恒量和靶焓法。主设置为`nuFactor=2, nuLocal=1, meshSmoothZ=100, Rdom=2mm, Zdom=3mm, rtol=.002`，流体/固体/光学一次元，位移二次元，最大BDF阶数1，自动Newton阻尼、最多25次迭代、每迭代更新Jacobian。网格验证用`--mesh 0.75`，时间验证用`--step '0.25[ns]'`。

本轮主例保留了早期已接受的同方程/同网格状态，并用`ResumeS4.java`和COMSOL官方CombineSolution拼接。各`*_resume.json`记录来源与真实重启时刻。重启不外推、不改变物理时间；导出只去除重复时刻。直接从零使用最终Newton设置不保证逐比特相同，但求解同一初边值问题；应使用相同数值/守恒门槛比较。

## 从真实解生成相机图

```powershell
python work/reproduce.py post MAIN
python work/reproduce.py post GRID --reference MAIN
python work/reproduce.py post TIMESTEP --reference MAIN
python work/reproduce.py compare MAIN GRID TIMESTEP
```

将`MAIN/GRID/TIMESTEP`替换为`delivery_state.json`中的实际工况名。主例只用0–80ns确定一个增益与一个固定时移。验证例通过`--reference`冻结主例相机参数；不分别拟合。未通过完整数值审计的真实部分解仅能显式使用`--diagnostic`，不会升级为有效主结果。

`ExportFields.java`导出真实有限元插值，物理坐标显式用米。`radiation_s4.py`计算可见谱线、free-free、吸收和轴对称视线输运；`camera_s4.py`执行10ns门积分及统一响应；`plot_s4.py/plot_metrics.py`绘图，`CreateViews.java`生成保留真实解的MPH结果视图。后处理插值网格不代替FE网格验证。

## 可见能量与源数据

```powershell
python work/visible_budget.py --tables
python work/run_standalone.py ExportVisible E:/COMSOL_CuPlasma_S4_20261105/work/MAIN.mph E:/COMSOL_CuPlasma_S4_20261105/results/MAIN_visible_budget.csv E:/COMSOL_CuPlasma_S4_20261105/data/visible_emission_tables.txt
```

380–780nm的全FE域未衰减发射积分为本轮指定谱线/free-free闭合的逃逸能量上界；450–550nm仅是相机敏感性通带。两者不能混同。若上界超过吸收能量5%，须进一步求净逃逸并按要求反馈重算，不能宣称后处理已足够。自由束缚、Stark及分子带等未建模项在报告中单列。

`run_standalone.py`中的Java进程工作目录固定为`work`；文件参数一律使用绝对路径，避免将`work/MAIN.mph`误解析成`work/work/MAIN.mph`。`reproduce.py`已经传入绝对路径。

实验入口为`experiment/S4_reconstructed.npz`，29帧全部保留；`reconstruction.json`记录裁剪、S2色条、400μm标尺及伪彩反演误差。`data/*.url`保留NIST完整请求。方法与限制见`发光与相机方法.md`，界面变换见`ALE守恒推导.md`。

## 审计和停止

数值审计入口`python work/audit_s4.py CASE`；图形审计入口`python work/run_figure_qa.py`。保存停止通过根目录`STOP_REQUEST.json`写入对应case及reason，由worker调用官方`-stop 100`。不终止COMSOL进程、不删除恢复文件。已有H00及未全时域通过的H系列结果均保留作诊断，不能用作最终S4支持证据。

## 官方检查点继续求解

单段达到45分钟或官方保存停止后，先读对应数值审计。只有除完整时域外其他检查均通过的真实检查点，才可用以下入口保持原设置续算：

```powershell
python work/reproduce.py resume REPRO REPRO_CONT
python work/reproduce.py solve REPRO_CONT --threads 8
```

程序生成独立ready和`*_resume.json`，继续后自动用COMSOL官方CombineSolution合并真实历史，再执行完整审计。不会把部分时间解改标为完整；累计4小时预算不会被清零。

本轮也按实际非线性表现切换过Newton迭代策略。迭代策略不改变守恒方程、网格、最大步、容差或稳定化通量；全部接受解仍需审计。可显式复现切换：

```powershell
python work/reproduce.py resume EARLY AFTER_EARLY --jacobian onevery --damping auto
python work/reproduce.py resume S4_CHECKPOINT LATE --jacobian minimal --damping const --damp 1
```

第二条为晚期冷却的直接成本尝试；是否实际获得矩阵复用、是否通过完整审计，以保存日志和最终报告为准。不得把早期已观察到的收益套用于晚期。所有结果和复现设置可在对应`*_settings.json`、`*_resume.json`及日志中追溯。

主相机修正取消了谱线与free-free的绝对发射截断，辐亮度以float64保存；极大增益不能使数值忽略的尾部成为真实光子。free-free在严格光深上界<1e−4时用解析通带积分（吸收忽略相对误差≤1e−4），其余保留频率输运。解析薄/厚检查见free_free_transport_audit.json。另有全FE域、全方向、跨全部允许时移的可见光子上界，不依赖NA或视线范围：`python work/photon_upper_bound.py MAIN`。
