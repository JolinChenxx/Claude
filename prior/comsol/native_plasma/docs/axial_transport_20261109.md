# 轴向输运支线：构建中的近似模型

均匀半球总体模型不能求出离面亮核的位置。A01 将气相分为 24 个固定轴向有限体积，每个体积各有一个原生 Plasma 接口，独立求电子能量、Cu0–Cu4+、空气反应和质量组分。质量、轴向动量、总能量及各组分使用一阶 Rusanov 通量；同一内部面的流出、流入严格相反。轴向范围 0–650 μm，网格在靶面附近较密。电子能量另含对流和电子压缩功，包含激发/电离能的总能量另行守恒。

这是准一维流管近似，**不是完整二维轴对称流动，也没有移动液面**。截面积暂定 A(z)=π[(11 μm)²+z²]，相当于一个固定扩张流管；它不是依据 S4 逐帧调整的半径，但其开角是待验证的几何假设，不能据此声称横向动量或羽流半径已经获得独立预测。所有结果必须携带这一标注。横向速度只在光谱传输中按流管扩张的运动学关系估计。

靶面用 H04 真正求解并保存的铜传热、蒸发、逐物种及焓历史。H04 采用 60 ns FWHM 高斯脉冲，半高点对应实验 0 和 60 ns，数值中心 148 ns，保留 118 ns 相机时移；它是未测定激光波形的敏感性分支。靶面预留 10% 激光，剩余 90% 在各气体单元间作前行、回程吸收，避免重复分配输入。铜面反馈仍未闭合。输入质量还携带热发射的平均法向动量，动能包含在同一输入总焓预算中。

上边界连常压静止空气；下边界对原有气体为反射壁，蒸发作为首单元质量、动量、能量及组分源。壁面变截面积压力项进入轴向动量。离开上边界的铜和能量纳入全局账。记录真实单元布居并按实际 z 坐标作侧向视线传输、475–525 nm 光谱和 10 ns 曝光；不另设亮核轨迹、位置平移、逐帧增益或光强。

已有双区反应数据和局部能量近似沿用。高价离子激发态、双电子复合及跨单元辐射反馈未解决；一阶通量的数值混合可能影响铜—空气接触层冷却。只有完成实际求解、守恒检查及图像比较后，才能判断这条支线是否有解释力。

各单元仍采用准中性全局 Plasma，没有显式空间电势或鞘层；不能把准中性代数约束当作独立的电荷输运验证。A02 另用已完整保存至 1 μs 的 G21–G44 近靶控制体出口作为输入，并关闭下游激光加热以免重复分配。它保留上游仅到 Cu⁺ 的高温截断缺陷，只用于供料/输运诊断。输入法向速度采用源层实际气体状态的等熵声速出口，再按均匀半球出口的轴向平均投影取 1/2；没有从 S4 反推速度。所有铜组分、总焓、电子焓与动量一同进入首单元。

构建：`generate_axial_component.py`、`src/BuildAxialPlume.java`；运行：`run_axial.py`；导出与成像：`src/ExportAxialPlume.java`、`post_axial.py`。
