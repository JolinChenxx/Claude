# 98.251 ns 停滞的质量通量诊断

F56 与 F60 在相同物理时刻附近持续缩步。最低氮气质量分数节点位于轴线、离靶面约 1.811 μm，w(N₂)=2.01×10⁻¹⁴；气温 10860 K，电子温度 40520 K，铜质量占比约 99.984%。该点的 N₂ 化学净源为正，不能直接解释为氮气反应耗尽。

检查实际原生方程发现：继承模型虽然打开了 `MixtureDiffusionCorrection`，其当前 Fick 表达式仍为摩尔平均扩散项加电迁移项，所有重粒子的扩散质量通量之和不为零；流体连续方程却按质量平均速度编写，仅含原有人工质量扩散。因此作为质量余量的 N₂ 被迫承担两套总质量通量的差。

`MassFluxAudit.java` 在 F60 保存解上的直接评估：

- 上述最低 N₂ 点的重粒子扩散质量通量之和，z 分量为 −4124 kg/(m²·s)，对流质量通量为 109420 kg/(m²·s)。
- r=0.1 μm、z=2.1 μm 时，扩散质量通量和的散度约 −2.60×10¹⁰ kg/(m³·s)，而当地 N₂ 化学质量源约 −7.90 kg/(m³·s)。
- 这说明不能仅通过缩小时间步处理，也不能把余量消失解释为真实反应损失。

F62 从初态重算，使用标准质量平均修正 `j_i = j_i(raw) - w_i Σ_j j_j(raw)`，同时包含离子迁移。现有各物种通量、扩散焓通量及电流读取同一修正后的原生通量。反应率、初始电子密度、激光参数及显示增益不变。F62 仍保留原有 log-ratio 组分坐标；先检验这个直接定位的通量问题能否消除停滞。

将修正后的通量表达式放到同一 F60 场上作代数检查，最低 N₂ 点的 z 向通量和从 −4124 降为 7.28×10⁻¹² kg/(m²·s)，其余抽查点也降到浮点舍入量级。这是通量恒等式检查，不是修正模型已经求出的新时间演化。

为提高早期无强反应阶段的效率，F62 保存至 2 ns 后，由 F63 在相同物理方程下继续：80 ns 前最大步长 1 ns，之后 0.05 ns。COMSOL 自适应误差控制始终启用。

另准备了 `PartialMassCoordinates.java`：全部重粒子使用对数分密度，包含 N₂ 的独立守恒方程，总密度由组分求和，不再让单一稀少组分承担连续方程余量。这属于后备结构方案，尚无有效求解结果。F61 的首次启动因最大时间步属性不接受 t 而结束，没有产生可用解；已按 COMSOL API 的 `maxstepexpressionbdf` 用法修正代码。

F60 主体羽流出现强电离及激光吸收，但尚未覆盖首帧曝光，且净电荷检查失败。它用于定位机制和数值问题，不作为实验吻合结果。

## 后续坐标修正

F63 在约 85.44 ns 再次持续缩步，正常停止并保存到 85 ns。该保存时刻的最低 N₂ 质量分数已降至 2.22×10⁻⁴，而当地氮气反应损失时间远长于本过程；其 N₂/O₂ 数密度比约 0.174，明显偏离初始空气比例。通量一致性修正本身不足以消除“微量 N₂ 承担独立总密度与其他组分离散误差”的问题。

因此 F70 启用上述全组分对数分密度方程，并同时保留质量平均通量修正，从初态重新计算。N₂ 也独立守恒，总密度严格由所有组分密度求和；不增加物质、不提高种子电子密度。

另对 F60 的 92 个实际接受时步作了同积分阶数的电荷审计：98–98.251 ns 的实际总电荷变化约 0.573 pC，而将原生方程的链式时间导数积分后仅约 −0.000148 pC。这说明旧 log-ratio 组分变量的离散时间链式法则造成显著电荷漂移，不能用反应源配平通过来替代真实保存解的电荷检查。F70 的分密度坐标也将针对这一点重新检查，尚未宣称通过。

## 96.9345 ns 实际接受步诊断

F70 在 0–96 ns 的铜、总电荷和能量残差分别约为 0.0118%、4.28% 和 0.532%。为避免按整数纳秒保存而错过停滞位置，F75 从 96 ns 的相同方程续算并保存全部接受步，正常停止于 96.93449997 ns。

该状态出现明确的电子雪崩：最大电子密度 3.34×10²⁶ m⁻³，最大气温约 15593 K，轴线 z=1.811 μm 的电子温度约 57911 K。羽流吸收功率从 96 ns 的 2.92 W 增到约 275 W。最低气温仍为 268 K，因而本次停滞不能归因于负气体热能。

最低 N₂ 点具有真实快速化学损失，已与旧模型中“氮气承担总质量余量”的机制不同。但另一个节点的微量 N⁺ 降至约 1 m⁻³，相对变化率达 2.61×10¹⁴ s⁻¹；需注意强梯度下的空间离散及微量物种问题。该处 N⁺ 的正反应源不能据此解读为物理耗尽。

按原生组装阶数 2 统计，96–96.9345 ns 的实际总电荷变化为 −0.01665 pC，而链式方程导数的积分仅为 +0.00000239 pC；峰值金属电荷为 0.03361 pC。实际漂移约占该尺度的一半，因此 F75 不作为可信实验对照。电子与离子反应电荷源仍配平。

F90 从初态计算，在原生 Plasma 的正值对数场之外加入物理分密度、电子密度及电子能量的 L² 投影变量，时间离散直接对物理守恒量作 BDF。输运、反应率及表面供料不变，目标是消除已确认的离散时间链式法则缺陷。此方案尚待实际求解验证，也不预先宣称已解决微量物种的空间问题。F80 同时运行匹配全组分分密度和质量平均扩散结构的中性基态供料对照。

另以 2、4、6、10、16 阶积分评估同一 F75 末态，其气相加金属总电荷分别为 −0.01645、0.02988、0.03913、0.04230、0.04233 pC。高阶结果收敛，但与原生组装的 2 阶结果差异超过金属电荷本身，说明除时间链式法则外，陡峭指数场的空间积分也需要修正。

因此准备了 F95（尚未求解）：用 `PlasmaDomainQuadrature.java` 将 43 个原生域弱式的完整表达式移到显式 8 阶积分，原表达式锁为零以避免重复；额外守恒对流、物理存储和投影采用同阶积分。方程表达式、反应与输运参数保持一致。该结构仅作为 F90 的针对性后备，不把“准备完成”视为验证通过。

后续检查发现，继承的电子—中性碰撞频率使用 `nHeavy-nN2-nO2` 作为其余中性粒子数，实际把带电重粒子也包含进去；这些带电粒子又进入电子—离子库仑碰撞项。F75 最大电子密度位置的重复中性代理项约为总碰撞频率的 31.9%，已影响羽流吸收与电子输运，不能保留到最终主工况。

F100 因此统一采用上述物理存储、8 阶积分，并在 `NeutralCollisionCount.java` 中将中性项明确改为 N₂、O₂、N、O 和中性铜各能级之和，带电重粒子只进入原有库仑项。没有改变截面或另设吸收率倍数。F100 于 09:02 UTC 从初态启动。F90 正常保存早期片段；F95 仅完成初始化和约 0.008 ns 接受步后正常停止，没有用于实验对照。F84 则继续中性基态供料的早期对照。

原先各阶段普遍使用 0.05 ns 最大步长，已改为自适应误差控制下的较宽上限，首曝光阶段 0.5 ns，后续阶段依次 0.5、1、2 ns；需要更小步长时仍由求解器自动缩步。后续正式收敛验证按实际主候选进行。

## 物理存储投影的修正

F100 在约 72.226 ns 持续缩步，尚未到强电离阶段，正常保存的插值输出只到 72 ns。其线性辅助存储场出现负的微量铜和电子节点，而原生指数密度仍为正；两者仅通过 L² 投影关联。将这种插值保存解作为续算初态时，非线性代数约束也不再精确成立。F105 的实际接受步诊断在约 72.000035 ns 出现冷区中性铜相对变化率 1.73×10¹⁵ s⁻¹，不能解释为高温铜电离。

F110 改用与 8 阶弱式积分点完全重合的 Gauss point data 存储，每个积分点直接约束物理密度，不再在空间中投影到连续线性辅助场。这正是 COMSOL 文档中 Gauss point data 用于局部历史量的用途。原生 Plasma 的电子、电子能量、重粒子、反应和电势仍保留；没有加大初始密度或反应源。辅助局部未知数增加到约 167 万，连同原变量约 176 万自由度，利用工作站内存求解。

有辅助物理存储的后续阶段改为保存最接近输出时刻的实际接受步，不再分别插值对数场与物理存储。光学仍只对实际保存时间覆盖的完整曝光进行时间积分。

F84 中性基态对照在约 100.36 ns 也出现持续缩步，已正常请求保存，并用 F86 的短区间实际接受步诊断定位。尚未获得修正工况的完整首曝光。
