# 近靶高密度供料层：独立诊断

G21 从 G12 的原生反应、频率积分逃逸概率和铜传热出发，把气相限制在半径、高度均为激光半径 11 μm 的半球形控制体。该长度只来自光斑，不从 S4 图像拟合。计算目的仅是判断把全部铜均匀摊入不断扩大的体积，是否掩盖了近靶电离和激光吸收。

外表面积为 2πR²，通过标准理想气体等熵喷口质量流率流向常压环境。压比达到临界压比后使用堵塞流。γ 由当前冻结组分的气体和电子压力／热内能确定。所有重粒子按本地质量分数流出；电子按准中性流出，电子能量扣除其焓流。总内能扣除相同物质携带的完整比焓，包含铜的参考能、激发／电离能及电子能。流出总质量、铜质量和能量分别累计，以便检查控制体收支。微小的通量正则化尺度仅为 10⁻¹⁰ kg/(m²·s)，未加入背景供料。

物理依据是控制体质量、能量守恒及等熵堵塞流关系。喷口代表未分辨的近靶过渡区，不能视作真实机械喷口；无外羽流压力反馈。这是尺度选择敏感的供料诊断，不是二维空间预测、显式鞘层模型或实验吻合结果。铜高温闭合仍沿用旧版本，其不足未在该诊断中消除。

不给控制体外人为添加光。若这里仍然没有明显的等离子体吸收，则不据此构造亮核；若有，将以实际流出物种与焓作为进一步守恒分区耦合的依据。
