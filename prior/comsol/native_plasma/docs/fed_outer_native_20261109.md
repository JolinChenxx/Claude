# 计算供料驱动的下游原生 Plasma

G45 使用 G21–G22–G23–G26 实际保存的近靶出口总质量、逐物种质量流率、完整焓和电子焓，驱动一个独立的下游原生 Plasma 与膨胀守恒模型。目的在于快速分清“靶面传热及高密度供料”与“外部气体反应及发光”各自造成的趋势，属于分段耦合诊断。

该下游模型没有第二个铜靶传热方程，没有重复添加蒸发供料。下游物种来源完全取自已保存出口通量，不能超出源数据的时间范围。源通量中仅将舍入造成的负微量组分归零，再将质量分数归一化，确保各物种质量之和等于原始总流率。修正量记录于 `data/source_feed_manifest.json`。

这是一向耦合：下游压力没有反馈给源层；源层的激光吸收也未受外羽流遮蔽。为避免重复分配同一激光能量，下游本身不再吸收激光，必须结合外羽流光学厚度评估这一近似。外区采用均匀半球及独立扫入空气薄壳，没有离面亮核位置预测。高温源仍使用只到 Cu⁺ 的旧反应集，不能把其高温电子状态视为完整电离闭合。

输出格式复用全局诊断，但能量输入字段代表“从源层注入的焓”，不是第二份激光吸收。源靶温度只作为读入的参考，靶内能不计入下游守恒账本。铜质量守恒也以出口注入量归一化，不冒充整个铜靶系统的总账。
