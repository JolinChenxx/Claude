# G08：原生整体 Plasma 的显式高能级对照

以 G06 为初态结构，增加一个原生 Cu I 3d10.5d ²D₅/₂ 物种 CuT5。能量 6.8676456 eV，光电离阈值 0.8587344 eV，1064 nm 光子为 1.1653 eV；现有最高的两可见上能级阈值约 1.534 eV，无法发生该单光子通道。

复用本轮已整理的 `data/tail5d_sources.json` 及速率表。NIST 能级与 406.2638 nm、A=2.1e7 s^-1；碰撞激发/电离采用 van Regemorter/Lotz，光电离与逆辐射复合采用同一 Kramers–Milne 近似。不是实测铜截面，未调节速率拟合 S4。

与早前 F11 不同，此处高能级有真实的原生质量分数未知量，不作准稳态消元。铜总量、重粒子热容、化学内能、靶面热分布供料及回凝都包括新增物种；已冻结的 CuP3/Cu+ 原生源增加对应化学计量项。光电离总吸收在总能中只出现一次，电子能量扣除电离阈值能，后者由化学内能保存。吸收的体平均强度由同一总吸收/光学厚度计算，两吸收通道按实际吸收系数分配。

该工况仍是均匀半椭球的整体模型，不能验证内部亮核、漂移位置或鞘层，也没有解决高温靶材状态方程。主要用途是判断可由1064nm光电离的真实高能级是否改变电离启动、羽流吸收及全时窗亮度趋势。
