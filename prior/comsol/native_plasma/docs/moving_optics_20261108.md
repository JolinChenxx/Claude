# 移动液面的光学后处理

`ExportMovingOptics.java` 从真实保存解读取每个径向位置的液面高度，在实际液面上方按距离采样气相。径向位置不变，空间高度为液面高度加采样距离。最近采样点距液面 0.1 nm；这只是后处理采样，未改变求解网格或物理方程。

视线积分仍沿真实空间水平射线进行。每个射线点先扣除对应径向位置的液面高度，再插值非 LTE 激发态、谱线吸收及连续谱；射线遇到铜体时按不透明靶材处理后方遮挡。没有把弯曲液面拉平成水平线积分。

当前结果明确为**主体羽流光学**：距液面不足 0.1 μm 的发射不加入图像。其光学薄体积发射率另行积分，记录在 `moving_optical_audit.json` 中，用来估计省略量，不能冒充已解析移动纳米鞘层。原始图像坐标从初始 z=0 开始，因此低于该平面的凹坑发射也不在当前取景范围内。

已用 F87 的平面结果做退化检查：把液面高度置零，123 ns 主体光学与原完整平面光学的积分辐亮度之比为 0.99811，逐像素相对 L1 差为 0.189%，峰值比为 0.99216。被省略薄层的光学薄功率估计为主体图像功率的 1.94%，其实际贡献受谱线自吸收抑制。此检查只支持这一平面保存态的后处理一致性；移动工况必须重新报告自己的薄层贡献。

M03 的 80 ns 保存态已通过液面随动采样，靶心高度与直接界面导出一致（约 −0.465 nm）。该早期态省略薄层的光学薄功率估计为主体图像的 0.0153%；此时尚无 S4 首曝光，不用它声称实验对应。
