# 01:00 机制与数值判断

本节只对应已保存至模型95 ns、假设实验零点为模型90 ns的首帧。不代表S4全时序。

## 首帧与辅助光电离

基线P201+P202和Cu 5d对照P203具有相同C201铜供料。85–95 ns曝光峰值分别26.9334和26.9429 W/(m²·sr)，理想收集光子总量108.5005和108.4985。共享色标下两者近乎相同；90%光子径向积分半径均5.56 μm，这个积分指标不等于论文灰度阈值半径。

95 ns基线气相铜质量0.02888 ng，累计蒸发0.03690 ng、回凝0.00766 ng。输出时刻梯形积分的质量残差约−1.23%，尚未达到1%验证目标，不将其等同于求解器离散守恒残差。气相累计激光吸收仅3.50 pJ，铜面累计吸收6.53 μJ；气相相对初态总能量增加0.239 μJ。可见这段计算仍主要由铜供料携带能量驱动，没有建立显著羽流激光吸收。

Cu 5d对照同一时刻的气相累计吸收3.502 pJ，仍未产生明显增益。有效含铜采样中消元态弛豫时间在80–95 ns内不超过0.019 ns（95 ns为0.0087 ns），库存占总铜不到8×10⁻⁹；这里只支持早期准稳态消元，不验证氢样光电离截面，也不排除脉冲峰值附近的变化。继续P204/P205同源对照，不调整反应率。

## 铜液面加密

C210把径向节点间距从0.5 μm缩小到0.25 μm，保持已有高度输运稳定化及原铜流动设置。保存至143 ns：抬升1.480 μm、中心回缩2.668 μm、峰值熔铜速度145.3 m/s。整体质量残差占蒸发量0.0147%，但局部法向运动残差在141 ns为106.1 m/s，143 ns为184.4 m/s。粗网格C208在141 ns为100.3 m/s。

结论：单纯径向加密没有解决后期液面运动误差。暂不继续加密扫描，也不将该后期界面作为可靠射流预测。早期120 ns残差约1.97 m/s，可与相同时间段粗网格比较；不能把早期表现外推到后期。

## 正在推进

C211从初态重算，将P201+P202实际压力、热通量、回凝、电子边界能量和透射率返回原C201铜离散模型，上限95 ns。属于第二次分块迭代，尚未达到双向收敛。

S201的80个原生Plasma单元已建成，接入二维有限体积输运和铜直接热反馈后进入初始化。其热状态铜发射、粗网格及无显式鞘层均区别于P系列，不能用两者差异单独归因于一个反应通道。

铜约8139 K峰温仍依赖未验证的高温物性外推；没有据此宣布相爆，也没有加入按图像大小反算的抛料源。
