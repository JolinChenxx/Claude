# COMSOL三项目标实施方案

2026-11-09。本文件回应物理复核后的实施方式，仅规划，未启动新增算例。目标是同一工况同时解释离面近圆形、首帧大而弱、中心持续发光后收缩变暗；目前没有证据保证某一个新增机制能独立完成这三点。

## 共同模型与求解路线

- 铜域：Heat Transfer焓法处理熔化；熔体流动含固相阻尼、表面张力和Marangoni应力，真实自由面由Moving Mesh/ALE追踪。近临界热层不能继续沿用常密度熔体和低温物性外推，需另行闭合多相状态。
- 气相域：二维轴对称可压缩质量、径向/轴向动量和能量守恒，采用已有一般形式/弱形式PDE结构，不能用低马赫数近似替代高速膨胀。Plasma接口保留空间分布的电子密度、电子能量、铜与空气物种及适用的电势闭合；核对对流、压缩功和ALE相对速度。
- 复用已有反应、材料来源和相机脚本。G系列和A系列只作诊断，不再将预设半球/流管作为形貌预测。D01的二维方向有参考价值，但24个独立全局Plasma单元和4×6粗网格不作为最终空间模型。
- 先用已核对的反应集建立空间输运对照；铜运动和气相分块求解，输出真实的界面位置、面积、质量、动量和焓历史，气相返回压力、热通量、回凝及激光遮蔽，在短时间窗内迭代。首次单向传递仅为预测步骤；界面交换和结果收敛后才称双向耦合。结构改变从初态重算，旧89 ns解只作回归参照。
- 初期ALE只承载连续液面及连通射流，不声称处理液滴断裂。采用已有共径向节点映射网格；如变形要求重划分，需守恒转移质量、动量、热能和物种。不能把失败网格投影后当作有效续算。相爆导致的分散凝聚相需要单独输运表示。

## 目标一：离面、近圆形的实际发光区

不指定发光区半径、圆心或上升轨迹。解出铜/空气输运与非均匀激发态，再由辐射输运产生图像。先确认径向和轴向输运能让铜云与亮区在物理上分离于铜面，再接回移动铜供料。固定铜面对照只用于辨别气相自身作用，不等待其独自匹配全部S4后才恢复铜运动。

界面法向由液体指向气体，净蒸发通量j为正时，采用质量跳跃关系

\[
V_n=u_{l,n}-j/\rho_l,\qquad \rho_g(u_{g,n}-V_n)=j.
\]

各铜物种的净通量总和与j对应，原子数、电荷、动量和焓同步交换。回凝由局部气相铜状态决定。表面张力进入应力跳跃；蒸发反冲由一致的动量闭合给出，不再与同一蒸发动量重复相加。能量采用一致焓基准，避免焓差和潜热重复扣除。

沿实际移动界面施加蒸发/回凝，供料的位置与面积由铜运动决定。高通量S12/S14的铜顶及亮区底边用于独立检查，不能用它们逐帧规定模型运动。近壁冷却、组分变化、自吸收与气相惯性均保留，因此离面发光不被预先归因于移动铜源。

视线积分沿实验空间坐标计算，铜体遮挡按实际几何处理；不能先把曲面拉平再积分。至少输出铜体轮廓、铜气相质量分布、电子密度、两种温度、发光区和冲击波位置。对照指标包括径向尺度、纵横比、亮区顶/底、光质心及它们相对铜面/铜顶的距离。

## 目标二：首帧已有较大弱光包络，随后中心增强

首先重建统一的激光—相机时序：400 μJ、60 ns、半径11 μm固定；空间高斯光斑定义、时间脉冲形状及相机零点分别列明依据。原文未完整给出的波形只能作少数有界输入比较，不能称为实测波形。118 ns不再当独立实验输入；同一时间映射用于全部帧，并满足原文约60 ns脉冲结束和10 ns曝光的约束。

激光沿光路按局部吸收系数衰减，含电子—中性和电子—离子碰撞吸收；到达铜面的剩余光按有依据的材料吸收率吸收，反射光继续传播。移除诊断模型固定10%/90%的能量分配。入射400 μJ只计一次，光传播中的吸收与反射/透射出口闭合。

在该条件下先看表面蒸发、气相加热与压力扩张是否能提供早期所需的物质和发射。弱光包络应分解为含铜谱线、空气在实际通带内的可能发射及连续谱；不能把冲击波位置直接当亮区，或用任意初始等离子体球填补首帧。

相爆作为有判据的分支：先取得热力学一致的铜多相EOS，并沿热层温度—密度—压力路径判断亚稳程度，结合体积成核和气泡增长时间决定释放。若满足条件，在铜的亚表层加入气液混合物移除，通过界面/源区向气相提供蒸气，同时对凝聚相设置独立质量、动量和焓输运；其后蒸发再进入气态铜反应。若原生接口不能表示该凝聚相，采用守恒Eulerian输运闭合；只有稀薄、粒径与阻力数据适用时才考虑粒子跟踪。

相爆抛出量来自热层状态和可用能量，不能由图像所需半径反算任意源项。材料数据尚不能支持时，报告机制区间，不能把8000 K外推或超过正常沸点当成既定触发条件。

## 目标三：中期亮核持续，随后缩小变暗

先对已有空间场分区核对热能、电离/激发储能、物质补给与外流。外边界由物质/能量前沿及实验视场确定，离开相机视场但仍影响羽流的气体应保留在求解域；以边界通量及一次扩域比较排除D01的显著铜出界干扰，不用反射边界强留物质。

在原生Plasma碰撞辐射反应中优先补充影响通带发射的上能级、复合级联和必要中间态，并包含竞争的碰撞退激发、再电离与空气附着损失。已有高电荷态不能直接全部复合到基态后再任意附加可见光；按实际电荷态布居、反应时间尺度与公开数据筛选反应。详细平衡和数据适用性决定速率，不以图像调整系数。

总能量账包含重粒子与电子热能、电离/激发能、动能及凝聚相焓。三体复合可将能量交给电子；辐射复合及级联产生光子。总能量包含化学能时，这些反应属于内部能量转移，不能再额外生成同一份热源。跨区再吸收用于能量转移，逃逸光才是净辐射损失。

谱线与自由—自由/自由—束缚连续谱由计算状态生成；有效光学厚度显著时，改进跨区辐射耦合，不能仅在图像后处理减光、动力学却仍扣除全部发射。热铜/液滴连续谱仅按其独立求得的温度、面积及有来源的发射率加入。新注入的铜若温度低、无能量来源，应允许它冷却羽流，不能自动发光。

相机统一使用10 ns曝光、同一空间标尺和固定响应。未获准确滤光片曲线时，475–525 nm明确作为假设并报告敏感性。对照中心辐亮度/区域积分光、弱光半径、亮核面积及离靶位置，区分“外围物质仍扩张”与“可见区跌破阈值而收缩”。

## 最少试错的实施次序

1. 固定成像与脉冲约束，处理现有域流失问题；在已有反应集下得到无预设形状的空间对照。
2. 分块接入真实铜运动与界面供料，短窗迭代反馈；先覆盖早期完整曝光，再检查高通量150–330 ns位置关系。每段均从同一物理初态历史连续推进。
3. 针对剩余偏差择一主改动：首帧缺料时验证高温多相/相爆；核心缺光时检查反应及储能释放。两项确有证据时再组合，不同时扫描波形、吸收率、反应率和增益。
4. 单一候选覆盖完整S4后，对相关时间窗验证网格、时间步、域大小及铜/电荷/能量账。所有阶段保留相同诊断和保存入口。

算力按有效任务分配：主空间求解使用一个NUMA节点约32线程，另一节点承担独立铜供料预测或后处理；只有实际吞吐更好才扩大单作业线程数。没有必要为填满64核启动无物理依据的参数扫描。

此方案需要解决的实质缺口是铜临界区材料数据、有效空间Plasma求解的效率、移动界面反馈和复合级联。它给出可判别的实现路线，不承诺单靠增加模块就能得到论文形貌。
