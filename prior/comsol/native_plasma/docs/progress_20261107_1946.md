# 第二小时进展（北京时间19:46，后续诊断更新至20:30）

P17 已保存全耦合 0–84 ns，包含原生 Plasma、气相、铜传热与流动、实际变形网格。空间场图位于 `figures/P17`。这段还早于 S4 首帧所需的 113–123 ns 曝光窗口，没有获得实验吻合结论。

## 已定位并修正

- 原生分子碰撞能量通道缺少低温退激发回馈，导致电子温度异常下降；加入详细平衡闭合后越过此前障碍。
- 默认等阶熔体速度—压力离散在强固相阻尼下产生振荡；改为二次速度、一次压力后，独立熔体从约86 ns推进到约112 ns。
- Nitsche网格速度约束未严格满足液面运动条件，铜体积损失约为蒸发量两倍；改为连续线性液面高度ODE和强制网格位移后，M11在100–114 ns的两者偏差降到约0.3%–1.3%。
- 原生液体传热替换手工对流热源；自动重划网格已触发，但新参考面与绝对高度的处理需要修正。M13验证位移=绝对高度−新参考面高度。
- 电荷积分的轴对称权重已修正。P18到80 ns的表面积分电流与气相电荷变化一致性明显改善，但这不等于所有时刻的收支已经验证。
