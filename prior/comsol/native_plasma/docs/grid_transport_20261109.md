# D01：粗网格二维轴对称输运诊断

A01/A02的预设流管截面使合成图被限制成锥形。D01复用24个已调通的原生Plasma单元，将其连接为4个径向×6个轴向有限体积，独立求径向和轴向动量。没有指定羽流半径、形状、轨迹或逐帧显示增益。

径向节点：0、11、45、130、400 μm。轴向节点：0、9、35、90、190、350、650 μm。每个单元体积为π(r右²−r左²)Δz，径向面面积为2πr面Δz，轴向面面积为π(r右²−r左²)。这是非常粗的探索网格，**不能据此声称形貌或半径已实现空间收敛**。输出场图显示真实单元边界。

质量、物种、两种动量及包含平动、电子和化学能的总能量使用Rusanov面通量；内部面在两相邻单元中的符号相反。径向动量含轴对称压力几何源2πpΔrΔz，静止常压初态的面压力与此源平衡。电子能量含两个方向的对流及电子压力压缩功。重粒子反应和电子能量仍由各原生Plasma接口计算，采用准中性闭合，不独立求电势或鞘层。

轴线和固定铜面反射；顶部与径向外边界接静止常压空气。流出的铜和能量计入全局账。H04实际热PDE的蒸发、组分、总焓及电子焓历史注入近靶首单元，法向动量按热发射速度给出。**径向源足迹未解析，当前将蒸发源集中于r≤11 μm；铜面没有羽流反馈或真实液面运动。**

H04采用中心148 ns、FWHM60 ns的高斯脉冲，属于未测激光波形敏感性分支。靶面预留10%能量；余下90%按1064 nm高斯光束各径向环带功率分配，沿每列作前行和反射吸收。曝光仍为10 ns、475–525 nm，模型时间减118 ns对应实验。

各单元局部谱线逃逸长度采用等体积球半径；跨单元辐射反馈未进入动力学。合成图另作逐环带前后分层视线输运，包含谱线、连续谱和多普勒展宽；环内径向多普勒速度作局部线性重建。没有把光学插值当作新增空间分辨率。均匀透明圆柱、四个径向单元的成像实现与解析弦长相差1.7e−15；这仅检验光学实现。

仍缺高价铜激发态、完整复合级联及近临界铜材料闭合。粗网格Rusanov数值混合可能显著影响冷却、铜前沿和亮区；即使趋势改善，也须空间加密后才可作为定量结论。
