# S4形貌、首帧尺寸与持续亮核：物理复核

2026-11-09。按用户最新要求，本阶段分析原文和已有保存解，未新增COMSOL算例。此前计算已结束；A01、A02、D01及G34–G36已覆盖模型1 μs，但均未同时满足S4形貌、亮度和位置演化。

当前最有依据的判断是：**应先恢复“凝聚态铜的运动—含铜气相输运—实际发光区域”的空间联系，重新约束激光与相机时序，再判断相爆和持续发光通道需要怎样加入。**目前不能把三项差异归结为某一个反应率，也不能认定加入相爆就会自动吻合。

## 1. 近圆形离面亮团与贴靶半球：首先是空间结构问题

图2的黄虚线明确标出上方Air、下方Copper，铜面不在图底边。此前对照排图将靶面放在裁剪底边，不能据此判断实验绝对离面距离。现有计算已经含铜原子和离子；真正需要区分的是静止铜基底、移动熔铜/液滴、含铜气相、周围空气/冲击波，以及其中能够被相机看见的发光部分。

图2和S3为低通量；S4为高通量。不能把图2铜面的像素坐标直接搬到S4。高通量的位置证据应采用Fig.4e、S12b和S14：铜飞溅顶端与选定亮区底边相关，S12b中灰度80轮廓对应较好，论文给出约344 m/s及约500 ns后高度趋稳。低通量对应阈值才是100。主文“亮核竖向停滞约200 ns并收缩”的量化描述主要对应低通量Fig.4a，不能当作S4已独立测得的停滞时长。

![原论文S14位置参照整理，非仿真](../figures/target_reference/S14_target_reference.png)

上图来自作者发表的合成图：白虚线为可见铜面，紫线为重建灰度80轮廓。150/210/330 ns的轮廓底部约距靶21/31/85 μm，仅作辅助位置证据；其裁剪与S4不一致，尚未建立唯一固定映射，不能逐帧平移配准。

现有模型有明确的形貌限制：G系列预设均匀半球/半椭球，A01/A02预设轴向流管截面。均匀、光学薄半球在侧视时满足

\[
I(x,z)=2j\sqrt{R^2-x^2-z^2},\quad z\geq0,
\]

其中铜面为z=0。因此它天然在靶面中央最亮，轮廓贴靶；改变整体发射率只能改变亮度，不能产生真实离面圆团。A系列的横向形状同样没有通过径向动量求得。D01已求二维输运，但4×6网格与固定铜面源不足以验证形貌。

物理上，气相可在压力和惯性作用下离面运动；近壁发射因冷却、组分变化或吸收而减弱，较上方区域保持发射，就可能形成离面亮团。上冲熔铜进一步把蒸发与焓输入位置带向上方，这是论文支持优先检查的机制，但位置关联尚不能证明它是圆形亮团的唯一成因。按344 m/s估算，500 ns位移可达172 μm；1 μs内重力位移仅4.9 pm，通常的热浮力不能解释这里的纳秒运动。

因此不应给模型强行规定一个上移圆球；应让质量、动量、能量输运决定物质位置，再由激发态和辐射输运决定哪些区域发光。

## 2. S4首帧已经大：相爆是候选，时序与烧蚀起始同样关键

S4在0 ns已有较大的弱光轮廓，随后20–60 ns明显变亮；这与“0 ns体积很小”不是同一个要求。后续比较必须把弱光外包络与中心亮核分开，不能只看最亮区域。

目前需要并列考虑三类解释：

| 候选解释 | 能解释什么 | 尚需什么证据 |
|---|---|---|
| 高通量更早开始烧蚀、电离并越过可见阈值 | 参考0 ns时已有较大弱光包络 | 激光前沿、曝光门时序及S3/S4统一成像条件 |
| 更强的压力驱动、气相加热及冲击波耦合 | 早期扩张更快、发光前沿与质量前沿不同 | 铜与空气分布、速度/压力及泵浦探测冲击波位置 |
| 过热液体相爆或其他体积抛出 | 短时间大量供料，蒸气与液滴混合喷出 | 可信温度—密度—压力路径、成核/增长时间、抛出质量和能量账 |

半径11 μm、能量400 μJ对应名义E/(πw²)约105 J/cm²；只有当w明确是高斯1/e²半径时，轴上通量才是约210 J/cm²。高通量相对低通量约为2.5倍，足以使吸收、蒸发和击穿出现非线性差异，不能仅按400/320的能量比解释。

相爆与普通表面蒸发不同：它需要过热亚稳液层中的体积成核和气泡增长，输出通常含蒸气与凝聚态液滴。现有约8000 K靶温来自高温物性外推，不能当作相爆已发生的证据。铜临界参数的文献模型也有差异，不能机械地以一个温度开关注入全部气态铜。原文提及的后续熔铜进入热羽流后“explosive evaporation”是一种解释，并非首帧近临界相爆的独立测量。

时序也必须纠正：118 ns是旧模型的图像拟合时移，不是论文独立标定值；补充材料没有精确定义0 ns对应光脉冲前沿、峰值还是曝光门中心。旧高斯中心120 ns加118 ns时移，会让实验0 ns之前已输入约47%的能量。另一方面，论文明确以约60 ns作为脉冲结束节点，这也是约束，不能据零点不详任意平移序列。10 ns曝光应由同一激光—相机时间关系积分；目前475–525 nm也只是模型通带，原文仅给约500 nm滤光片。

## 3. 数百纳秒亮核：必须解释持续布居及能量来源

按已有NIST来源线表求全部已纳入辐射分支之和，CuP3寿命约7.1 ns，CuH3/H5约13.3 ns。这些是光学薄自发辐射时间尺度；碰撞和辐射俘获可改变有效演化。不能单取510.55 nm一条谱线的1/A约500 ns作为整个上能级寿命，因为同一上态还有很强的紫外跃迁。

因此，数百纳秒亮核需要持续的再激发、复合级联、辐射俘获或其他发光组分。优先检查：

- 密集核心保留的电子/气体热能维持碰撞激发。
- 电离储能通过复合与级联释放；一次电离的铜约储存11.7 μJ/ng，但500 nm附近的份额和释放速率仍需反应数据决定。
- 上冲熔铜或热液滴持续补充铜和焓。蒸发本身耗热，供料不能被当作免费热源。
- 凝聚态铜的热连续谱及谱线自吸收/辐射俘获。单个通带不能确定其占比。

外围密度和激发率下降较快、核心仍有能量与粒子补给时，可出现“物质仍在扩张，而可见亮区收缩变暗”。这不要求全部铜物质向中心回流，也不等同于电子密度轮廓收缩。

已有D01还有具体的数值干扰：按旧118 ns映射，到实验200/260/400 ns，累计出界铜分别占累计输入约22.5%/31.0%/46.4%；模型1 μs时为74.2%。因此其过快变暗不能全部归因于真实复合和冷却。出界质量比例不等于亮度损失比例，扩域也不保证自动保住亮核，仍需分开发射损失、物质流失和粗网格混合。

## 4. 再进入COMSOL之前，收敛到以下可判别问题

1. **坐标和时序：**用高通量靶面参照约束铜面、铜顶、亮区顶/底与质心；分别统计弱光外包络和亮核。时间输入需同时符合60 ns脉冲、10 ns曝光与原文时序描述。空间/时间未知量应报告范围，不能逐帧调节。
2. **已有结果的物理账：**按近靶、核心、外层分解铜质量、热能、电离/激发储能、外流和可见发射；辨别为何核心过早失光。总账守恒不代表这些分配已正确。
3. **决定铜的供料方式：**检验表面蒸发与移动熔铜能否提供所需质量、动量和焓；若不能，再用有出处的多相状态方程与体积成核关系检验相爆。气态铜和凝聚态抛出质量分别计算。
4. **只推进最有证据的改动：**真实二维输运与移动供料是形貌主线；持续发光通道按时间尺度和能量账选择。相爆若缺判据，应保留为有界机制比较，不能当成既定事实或拟合旋钮。

目前可以确定的是旧简化几何不能验证离面圆形形貌、旧时移不能视为独立实验输入、长余辉不能由一次原子激发自行维持。仍不能由单通带图像唯一确定相爆是否发生，以及复合、碰撞激发和热连续谱各占多少。
