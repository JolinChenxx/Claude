# 激光时序与实验零点的核对

原文第 3 页（DOI 10.1002/lpor.202400388）将实验 0–60 ns 描述为激光照射阶段，并称亮度在脉冲结束附近的 60 ns 达峰。补充材料只提供 60 ns 脉宽，没有给出实测光功率时间波形。

继承模型使用中心 120 ns、FWHM 60 ns 的高斯脉冲。118 ns 时移来自旧 B64A 图像分布拟合（原 camera_s4.py 的 60–120 ns 扫描），不是独立的激光计时测量。组合这两个设置后，实验 0 ns 已对应入射总能量约 46.9% 的时刻，近于脉冲峰值。这使得新模型的发光峰早于实验，并不完全是反应物理的问题。

G10 是单独标记的激光包络/零点敏感性工况：从 G08 初态模型出发，保留全部物种、反应率、原生 Plasma、400 μJ、半径 11 μm 和 118 ns 相机时移；将激光定义为数值 118–178 ns 的近矩形脉冲。边缘使用 1 ns 的 erf 过渡，FWHM 为 60 ns，解析积分仍为 400 μJ。实验 0 ns 对应前沿半高，实验 60 ns 对应后沿半高。没有以发光峰反推新的时间偏移。

这不是实测波形，也不能据此宣称确定了实验激光输入。它用于检查“近矩形 60 ns 照射”这一与论文文字一致的输入假设是否改变先暗、后亮的顺序。原高斯工况保留为对照。若趋势改善，需将波形和零点列为输入不确定性，不能将该改善全部归因于新反应通道。

G10 仍为体平均等离子体与半椭球几何闭合，不预测内部亮核、靶面间隙或真实空间场。高温铜材料闭合尚未修复。
