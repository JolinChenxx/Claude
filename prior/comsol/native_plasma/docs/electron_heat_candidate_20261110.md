# 电子热输运候选：尚未加入主线

97 ns 已保存场的独立检查表明，电子热扩散可能与当前纳秒演化竞争。95.25 ns 可见发射率加权的热扩散时间中位值为 5.40 ns，平均自由程与温度梯度长度之比中位值约 0.00173；因此首先检查经典局部电子热流，而不是增加发光增益。

从局部能量近似的漂移扩散通量，在电子相对粒子通量为零时可得

\[
q_e=-\frac52n_ek_BD_e\nabla T_e,\qquad D_e=\frac{k_BT_e}{m_e\nu_m}.
\]

这里的碰撞频率仍采用当前原生反应模型继承的数据。数密度用单位总体积的电子数，因而导热系数已含气相体积分数。该项只输运电子能量，既不补充电子，也不代替完整电荷漂移、电子扩散和鞘层。

`electron_heat_transport.py` 使用轴对称面面积和实际网格体积，以面导热系数调和平均、隐式有限体积形式求解。每个内部面的一出一入严格配对；相同能量增量同时进入总能量和电子能量。外边界暂用零相对电子热流，边界平流仍属于材料输运方程。系数每子步更新；稀薄高 Knudsen 数区及稠密强耦合碰撞闭合仍需另行判断，当前算子不能解释为已验证的全区域热传导模型。

在 HC445 的 97 ns 场上，独立推进 0.25 ns 可重新分配 0.0367 μJ，占初始电子热能 0.651 μJ 的 5.64%。内部热流能量残差约 −5.10×10⁻²² J；组分与电子数保持不变。两个 0.125 ns 子步与一个 0.25 ns 子步的电子能量场 L1 差异为 1.49%。这只是固定组分的局部时间步检查，不是完整耦合收敛性验证，也没有新的合成 S4 图。

结果：`results/HC445/electron_heat_operator_audit.json`。主线仍不启用本算子；完整早期序列得到后，结合铜前沿、供料及发光位置判断是否作为下一项主导修正，并从物理初态重新计算。
