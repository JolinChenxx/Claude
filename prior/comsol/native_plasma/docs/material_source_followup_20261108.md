# 高温铜数据补充检索

09:00 UTC 前后补充访问了 JIHT 的公开数据库：http://www.ihed.ras.ru/rusbank/ 。页面可访问，并能选择 Copper（数据库物质编号 45），但其当前公开计算入口仅列出 KEOS5 和 KEOS7。

数据库自述将两者定义为压力关于比体积和内能的半经验量热状态方程，用于冲击压缩、卸载和二次冲击。当前取得的页面没有提供本轮所需的铜固—液—气共存、温度反演及临界区完整表格。它们也不能直接视作 Autrique 文中使用的 ITTEOS 5.8 多相数据。因此没有将其装入模型。

原始页面保存为 `data/round2_references/ITTEOS_*.html`。此检索没有解决高温凝聚相闭合的限制，也没有改变现有材料参数。

## 16:20 UTC 的图表核对

已直接渲染 Demin 等 2019 年论文的 Fig.2–4，保存到 `figures/material_data/`。Fig.2 的图例将低密度蓝色支标为 liquid、高密度红色支标为 vapor，明显与物理相支相反；临界点横坐标也约在 6800 K，而正文及 Fig.3/4 标注 6550 K。因此不能不加核对地将该图数字化后称为可用的完整铜 EOS。Fig.4 饱和压力曲线与正文临界压力 0.16 GPa 一致，但单独的压力曲线仍不能提供内能和相变供料。

新增检索取得俄文原稿 DOI `10.15372/FGV2023.9363` 的元数据，与既有英文铜多相 EOS 文献是同一研究；目前仍未取得全文或参数表。没有把元数据页面误作数值物性来源。
