# 方法一：原生等离子体耦合计算说明

本轮建立了 COMSOL 6.4 原生 Plasma 与传热、熔化、熔体流动、可压缩气相和真实移动网格的耦合工程。**当前仅有部分时间段可信的数值解，尚未实现论文 S4 的有效吻合、可信射流或 0–1 μs 全时段计算。** 最终状态见 session.json 和最新小时记录。

## 相比旧B64A增加了什么

旧工程的LTE状态闭合不再直接指定电子数。新工程分别求解电子与气体能量，通过电子碰撞、激发、电离、复合、附着、辐射和壁面电流耦合。铜由各Cu物种求和，不再叠加一套旧铜输运方程。液体有熔化潜热、固相阻尼、表面张力与Marangoni作用、蒸发反冲及真实液面位移。

这是模型结构的扩展，**不是已证明实验吻合优于旧模型**。当下最大的成果是获得可检查的非LTE反应、电子与液面耦合链，并识别此前会被“算出了图”掩盖的数值错误。

## 目前能支持的机制认识

近靶面热电子发射与返回通量很大，彼此几乎抵消；电子峰主要位于很薄的壁面层，不能把最大电子密度直接当作整个羽流的电离程度。铜蒸气与激发态在近靶面同时出现，远离靶面的铜供料和电子能量较弱，现有诊断图表现为紧凑亮区。

P72曾输出完整113–123ns曝光，光子量级并非零，但后续曲边网格检查发现曝光内有反转单元；已撤回其物理对照资格。该图只能提示“当前近靶面辐射集中过强/范围不足”的待验证问题，不能作为论文吻合结论。

现有材料没有独立电子密度测量；即使未来图像吻合，也需要单独说明电子密度的验证程度。

## 必须保留的数值发现

1. 原生对数重粒子输运与外部可压缩连续性需要保守质量通量配对。采用正的归一化组分并补齐链式导数，避免氮气余量负值/趋零奇异。
2. 铜面电荷弱约束的反力是每弧长量，不能误乘面积积分；壁面净电流对积分阶数敏感。
3. ALE边界通量必须使用实际离散网格速度。把未投影的液面运动输入速度直接用于通量，会造成虚假的电子收支。
4. 连续一次液面与二次液体速度不匹配时，可产生相邻单元数千m/s交替振荡；二次液面改善该问题，但曲边网格必须另查。
5. 单看求解器接受步、正常保存或节点相对体积不够；保存时刻的曲边质量和实际Jacobian必须同时为正。P72、P74、P83均有已明确排除的时段。

## 近似与未完成项

常物性铜与Clausius–Clapeyron表面蒸发被外推到约8000 K以上，临界区闭合不可靠。未引入完整相爆炸、液滴断裂、成核或沉积。Cu输运与部分碰撞率仍为半经验；分子内部激发采用快热化近似；谱线后处理包含Doppler及速度位移，自由–自由和近似自由–束缚连续谱，尚缺Stark/自然线翼。

最关键的后续工作是：在不反转的网格上跨过首帧曝光；闭合能量与高温蒸发/回凝动量；判断近靶面的电子能量与供料是否足以产生实验的扩展亮区。取得有效实验对照后再做对应时间步减半与局部网格加密。本轮尚未完成这项最终收敛验证，也没有冻结相机增益。

## 运行示例

在项目根目录，用 `runtime/Python311/python.exe -X utf8 route1/run.py compile 类名` 编译Java。构建后通过 `route1/run.py solve 工况名` 运行 `models/工况名_ready.mph`，输出真实解 `models/工况名.mph`。环境变量 `ROUTE1_THREADS=32`、`ROUTE1_NUMA=0` 或 `1` 控制单插槽作业；两个独立求解可各占一个插槽。

使用 `postcase.py 工况名` 导出并核查。若网格检查有负值，不能继续把该时间区间送入曝光积分。`ContinueSaved.java`继承真实保存态，但不同ALE表述的初值映射不能假定自动有效。
