## 已确认的COMSOL接口细节

1. 原生接口类型为ColdPlasma。重粒子用对数质量分数，电子密度和能量也用对数变量。通用PDE在轴对称几何中仍需显式乘r/Rdom。
2. 固体HeatTransfer在材料坐标系中储能，额外熔体热对流使用液体速度减网格速度。
3. 无外加电压的导体用MetalContact的Current=0，计入位移电流、原生电子墙面电流及额外HeavySpeciesFlux产生的离子电流。单纯FloatingPotential=Q0不具备粒子电流累计功能。
4. 原生Wall的电子热损失系数为0.5*n*vthermal；已直接引用原生通量用于电荷、能量边界，避免另用1/4系数。
5. Plasma在内部铜/气边界的up/down侧选择不稳定；电子迁移墙通量改用明确的铜向气体法向。
6. PrescribedNormalMeshVelocity的初始网格方程失败。已跑通的设置：PrescribedMeshVelocity、径向网格速度0、竖直速度w+u*ncr/ncz-mdot/(rhoCu*ncz)、Nitsche约束、Laplace平滑。这是真实变形网格，适用于尚无翻卷的单值液面。
7. Fick模式不能同时要求扩散系数由迁移率反算，否则原生D与迁移率形成循环。当前指定D，由Einstein关系计算迁移率。
8. 原生带电物种初始输入是数密度。初始总中性数密度锁定于pAmb/(kB*Tamb)，仅用于初始化，求解时仍用实际气相组分和温度。
