# S4 三项偏差的物理诊断（2026-11-09）

本轮仅核对现有数据与文献，不启动 COMSOL、不修改求解代码。原图核查见 [paper_evidence_20261109.md](paper_evidence_20261109.md)，数量级计算见 [physics_scales_20261109.json](../results/physics_scales_20261109.json)。

**目前最有依据的判断：应把“凝聚态铜的上冲—含铜羽流的供料与电离—实际可见发射”联系起来。离面亮区、首帧大和后续亮核是三个相关约束，单独增加反应率或调整显示不能解释它们。相爆值得重点检查，但已有图像尚不能确认其发生，更不能确认它支配了首帧。**

## 1. 为什么实验近圆形且离面，现有模型却贴靶？

必须分别跟踪静止铜基底、移动熔铜/液滴、含铜蒸气和离子、周围空气、冲击波及可见亮区。主文图2明确画出 Air/Copper 分界，图底边不是铜面；也不能反过来将整个彩色亮团都当液态铜。现有模型实际有铜物种，缺项不能概括成“把铜都算成空气”。

原文 §2.4 直接描述羽流底边持续上升，亮核在竖向停留约200 ns并收缩；这段量化描述主要对应低通量Fig.4a–c，不能当作S4高通量已验证的停滞时长。低通量泵浦探测图S10显示约50 ns熔铜开始隆起、100 ns左右弹起；高通量喷溅约344 m/s，约500 ns后高度趋稳。高通量 S12b 中铜顶与羽流底最接近的是灰度80轮廓，低通量才是100。该观测支持优先检查移动铜源进入亮区后的供料、焓输运与辐射，但不直接证明唯一成因。

344 m/s维持500 ns对应172 μm位移，足以改变供料位置。1 μs内重力位移只有4.9 pm；200 μm尺度的浮力时间约4.5 ms。因此这个时间段的上升应由压力、反冲和惯性分析，不能解释为通常的热浮力上升。

亮区边界来自视线积分发射与吸收，并非铜质量边界或电子密度边界。近靶区因冷却、吸收、组分/电离度变化而变暗，已离面的密集区域继续发光，就可能形成离面亮团。移动熔铜进一步把蒸发源带到上方，但移动源本身既不是离面亮团的必要条件，也不能保证形状自动变圆。

模型结构限制需要先承认：G系列的半椭球是预设几何；A01/A02锥形受预设流管面积约束，不能据其形状选择化学反应。D01已求解二维轴对称输运，但只有4×6个有限体积单元、固定靶源且无液面反馈，尚不能判断真实形貌。

**对应的前置工作：**用同一高通量条件的 Fig.4e、S12b、S14建立铜面、铜顶、亮区顶/底和中心的坐标关系；S4裁剪底边不能直接设为铜面。图2/S3是低通量，不能直接给S4配准。映射未确定时先比较半径、面积、纵向跨度，再报告绝对位置不确定性，不能逐帧平移拟合。

## 2. S4首帧已大，是否需要相爆？

相爆是重要候选，不能由首帧大或温度超过正常沸点直接确认。须检查过热亚稳液体的温度—密度—压力路径、体积成核和气泡增长时间，以及突然增加的气液混合抛出量。蒸气与凝聚相质量、动量和焓需要分账；不能将整份抛出物直接注入成气态铜。

Autrique等的多相模型明确区分表面蒸发/回凝、亚稳区气泡导致的体积移除、超临界移除。它说明相爆类过程可能在短时间供给大量材料并改变激光屏蔽，因而具有解释早期大尺寸的方向性；但其Cu–He、6 ns、266/532 nm条件不能提供本实验空气、60 ns、1064 nm的直接阈值。原文“explosive evaporation … is believed”主要讨论后续上冲熔铜进入热羽流，不能等同于实测首帧近临界相爆。

固定半径11 μm、400 μJ时，名义 E/(πw²) 为105.2 J/cm²。若11 μm是高斯1/e²半径，轴上通量为210.5 J/cm²；若60 ns同时为时间高斯FWHM，轴上峰值约3.30 GW/cm²。高低通量约105/42，即2.5倍，并非仅脉冲能量的400/320。熔化吸收率变化、蒸发和击穿的非线性，已可使高通量更早达到可见阈值。

热扩散长度的量级约1.3–2.6 μm；光斑对应此层内约4.6–9.0 ng铜。以40 μJ吸收能作示例，其比能约4.5–8.8 MJ/kg，说明强相变在能量上值得检查。这只是尺度估算，未扣除传热、反射、羽流屏蔽等，不能证明相爆。临界铜数据仍有分歧：Autrique模型取Tc约7800 K，Demin等2019的MD估计为6550 K、ρc约1.895 g/cm³、Pc约0.16 GPa。此前外推铜物性得到约8000 K，不能作为已进入相爆的可靠证据。

**时间零点必须同时处理。**补充材料没有明确0 ns是光脉冲前沿、峰值还是曝光门起点/中心。旧高斯中心120 ns与118 ns相机时移组合，使实验0 ns已经累计输入约46.9%能量；118 ns来自旧图像拟合，非独立同步测量。当前近矩形脉冲也仅是输入假设。若严格要求物理0 ns前毫无羽流，却在5–10 ns内出现150–200 μm半径，则表观前沿速度需15–40 km/s；这首先要求核对时序、门控与可见阈值。发光前沿并非物质速度，不能仅据此否定实验。

下一步应先列出时间输入的可接受范围，并用可信多相闭合判断是否真正需要体积抛出。不能靠平移整个序列或加入无出处的大质量脉冲来“证明”相爆。

## 3. 为什么数百纳秒后仍能有亮核？

中心的密度和储能高于边缘时，碰撞激发与复合可能持续，外围先低于可见阈值，于是出现“物质继续扩张、可见亮区收缩”。在简化光学薄条件下，碰撞激发发射常随ne·nCu及激发率系数变化，复合发射常随ne·nion及复合系数变化；高密度、非平衡和光学厚条件下不能直接套用单一比例。

需要逐项核对四类来源：电子/重粒子热能维持的碰撞激发；储存电离能的复合级联；移动熔铜和热液滴携带的质量及焓；凝聚态铜的热连续谱。谱线自吸收、辐射俘获与逃逸率也会影响可见持续时间。蒸发本身耗热，持续供料不能被当作额外免费热源；光学再吸收也只是能量转移，不能再次计入总发射净损失。

已有NIST线表给出以下光学薄自发辐射时间尺度：CuP3所有已纳入分支A之和约1.4174×10⁸ s⁻¹，寿命约7.1 ns；CuH3/H5约13.3 ns。**不能只取510.55 nm单线的1/A≈500 ns作为整个上能级寿命**，因为CuP3还有很强的324.75 nm紫外分支。因此数百纳秒亮核不能由同一批自由激发原子缓慢衰减解释，必须存在补给、再激发/复合、辐射俘获或其他发光组分。

一次电离的Cu约储存11.7 μJ/ng。几ng铜有几十μJ的电离能尺度，故脉冲后余辉在能量上并不荒谬，但实际释放速率与500 nm附近所占份额须由碰撞辐射模型决定。作为另一个尺度，3000/4000 K黑体在500 nm附近50 nm带宽内辐亮度约1.3×10⁴/1.4×10⁵ W·m⁻²·sr⁻¹；真实铜颗粒还要乘波长、尺寸相关的发射率和有效发射面积。该估算只说明不能先验排除热凝聚态发光，不能证明其主导。

现有D01衰减也受计算域流失影响。根据保存的累计输入/输出铜状态变量，流出比例为：

| 实验时间（仍按118 ns映射） | 累计出界铜 / 累计输入铜 |
|---|---:|
| 60 ns | 0.77% |
| 200 ns | 22.47% |
| 260 ns | 31.02% |
| 400 ns | 46.42% |
| 740 ns | 68.49% |

模型到1 μs时出界74.15%。260 ns后几乎不可见不能全部解释为真实复合或冷却；还须区分真实外流与粗网格数值扩散。该数值不说明31%的铜流失必然造成同等比例亮度下降，也不说明扩域后就会自动保持亮核。

## 4. 建议的下一步物理判别顺序

1. 完成高通量铜面/铜顶/亮区配准与时间零点审计，分别约束弱光外轮廓和高亮核。
2. 对已有保存解做分区质量与能量账：近靶、亮核候选区、外层；分清输运离域与实际反应/辐射衰减。不用显示增益弥补缺失发射。
3. 将可信的多相铜闭合与移动供料作为重点物理候选，先判定供料是否需要相爆/体积抛出，再决定自由表面、凝聚态抛出与气相注入的具体结构。
4. 分解可见谱线、复合/自由自由连续谱与凝聚态热辐射；以“半径—亮度—铜面相对位置”三个序列共同判别，随后只改动证据最强的一至两项进入COMSOL。

这些检查能缩小机制范围；仅凭约500 nm宽带图，不能唯一反演电子密度、相爆强度或各辐射通道。475–525 nm目前仍是模型通带假设，原文未给确切透射端点。
