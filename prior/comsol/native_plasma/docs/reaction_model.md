# 反应、输运和辐射数据说明

本表记录当前实现依据，不代表所有近似均已验证。逐反应公式、阶数和来源见 `data/reaction_source_table.csv`；实际插值数据、物种及能级见 `data/chemistry.json` 和 `data/log_rates.txt`。

| 项目 | 依据 | 当前实现与限制 |
|---|---|---|
| Cu I 能级、统计权重、跃迁概率 | NIST ASD，下载原表保存在 data/Cu_I_300_1000.tsv | 保留基态、低亚稳态、共振态和主要可见上能级；不是完整铜原子模型 |
| Cu 基态电子碰撞激发 | Winter 与 Hazi，1982，DOI 10.2172/5526164，表 V、VI | 使用原表截面，阈值插值、高能反比尾；细结构按统计权重分配 |
| 激发态之间允许跃迁 | van Regemorter，DOI 10.1086/147445 | 固定有效 Gaunt 因子 0.2；未通过图像拟合 |
| Cu/N/O 电子碰撞电离 | Lotz，DOI 10.1086/190154；铜资料 DOI 10.1007/BF01394789 | 价电子近似；激发态使用相应阈值，不包含所有壳层 |
| 三体复合、碰撞退激发 | 相同正向截面的 Maxwellian 微观详细平衡 | 稳定计算阈值移位积分，避免低温指数相消 |
| 辐射复合 | Kramers 光电截面与 Milne 详细平衡 | 氢样近似，非铜实测数据；总辐射能量采用同一核的能量矩 |
| N2/O2 电子碰撞 | COMSOL 自带 Phelps 空气截面 | 使用 Maxwellian 平均，局部电子能量近似 |
| 分子内部态能量回馈 | 微观详细平衡 | 未分辨的低能内部态采用气温热化、有效等简并双能级闭合；Te=Tg 时净交换为零，非分子态逐级模型 |
| 空气附着、解离复合、脱附 | Kossyi 等空气动力学子集、COMSOL 氧反应 | 源头条目仍须逐项复核；固定速率，不作自由拟合 |
| 热解离及逆反应 | Park 形式与基态配分函数 | N2/O2，N2/O2/Cu 为碰撞体；缺少完整振动态分辨 |
| 重粒子扩散与迁移 | Fick 输运及 Einstein 关系 | 简化混合扩散；中性碰撞参数含硬球近似 |

电子密度、电子能量、重粒子输运、电势均由原生 Plasma 接口求解。压强由重粒子温度、电子能量和实际组分得到，不用旧 LTE 电离度闭合。

475–525 nm 的首版辐射包含 Cu I 510.5548、515.3238、521.8202、522.007 nm 谱线，以及自由—自由、自由—束缚连续谱。谱线使用计算的上下能级布居，视线中计入热 Doppler 展宽、径向流速频移和吸收。当前尚未包含 Stark/自然展宽翼，也未加入空气激发态的可见谱线。

像素内进行面积积分，时间上进行 10 ns 曝光积分。早期方案使用118 ns时移；2026-11-10本轮P/HC链按已确定方案使用实验时间=数值时间−90 ns，每个输出的method.json记录实际映射。仅在完整覆盖实验 0–80 ns 的标定帧后生成一个共同增益并冻结，后续算例复用该增益。另输出 W/(m²·sr) 辐亮度和理想收集光子数，不能用显示增益替代实际光子支撑。

S4 来自论文伪彩图重建，没有独立电子密度测量，也没有独立靶面位置标记。图像形状/亮度对应、电子密度机制解释、绝对空间位置的证据强度分别说明。
