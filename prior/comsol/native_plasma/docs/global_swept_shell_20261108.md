# 热羽流与扫入空气分开的整体模型

G03–G09 的整体模型将全部被外缘扫过的空气立即均匀混入铜羽流。实际激光羽流可存在铜—空气接触界面；“立即完全混合”会使铜激发态、电荷与冷空气在整个体积内碰撞，并把空气质量直接加到热核心。G06 在后期接近室温，这一闭合有必要单独检查。

G16 从 G12 的初态开始，保留原生非 LTE Plasma、电子/气体两种温度、铜靶传热、全部反应率以及谱线逃逸修正。铜羽流与扫入空气通过一个薄壳动力学闭合相连：没有把新增空气均匀注入原生热羽流物种。原生气相保留初始11 μm半球内的空气。

半球体积 V=2πR³/3。热气体采用同位膨胀速度 u(r)=Rdot*r/R，其动能为3/10*Mgas*Rdot²；扫入空气薄壳的动能为1/2*Mshell*Rdot²。有效惯性质量 I=Mshell+3/5*Mgas，P=I*Rdot，dP/dt=2πR²*(p-pamb)。Mshell 的增加率为 rhoAmb*max(Vdot,0)。这些系数来自半球体积分，不作拟合。

热羽流内能变化率为靶面供料净焓、激光吸收减辐射、减p*Vdot，加3/10*Msource*Rdot²的质量加载项。薄壳单独记入空气输入焓和1/2*Msweep*Rdot²的冲击热。两者与动能相加后，严格得到外界压力功、输入焓和辐射的同一总能量账本。靶面源中的能量与原模型一致。

该分区是“完全混合”以外的物理极限对照，不能认为实际界面无混合，也没有解析接触面、冲击层厚度、壳温、壳内电离或壳辐射。光学只使用原生热羽流的激发态，薄壳不被人为赋予光亮。半球内仍均匀，因此内部亮核、靶面间隙仍不是空间预测。高温铜闭合的局限继续存在。
