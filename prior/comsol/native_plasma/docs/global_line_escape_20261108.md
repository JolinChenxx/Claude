# 全局模型辐射逃逸修订

G03–G05 已保存到 1 μs。晚期温度降至约 300 K，但 Cu 4p 布居仍被强共振吸收保留，产生微弱可见余辉。其总光子很少，不能用相机增益把整个冷羽流视为已验证的亮区。

已定位的闭合不一致：反应中的 `A*beta` 使用球体的灰体（线心光学厚度）逃逸概率；相机计算却对 Doppler 线型及膨胀速度梯度积分。光子逃逸不仅在线心发生，线翼和膨胀会增加逃逸。这一差异会同时影响激发态寿命和辐射能量收支。

`prepare_global_escape.py` 直接积分均匀膨胀球体的形式辐射输运方程，表格变量为线心径向光学厚度和膨胀边缘速度/热 Doppler 速度。无自由逃逸长度或寿命乘数。80 与 160 阶积分的代表点相对差小于 1.8×10⁻⁵。线型仍为纯 Doppler，尚未加入碰撞/Stark 展宽。

在 G04 的 118 ns 保存态上，修订的 324.8 nm 共振线逃逸概率为旧值的约 4.33 倍；510.6 nm 为约 3.30 倍；515.3/521.8 nm 为约 2.58/2.71 倍。这是同一保存态的闭合诊断，不是新演化结果。

G12 从 G08 初态重算，使用同一频率积分逃逸概率驱动原生辐射反应及总辐射能量损失。保留高斯激光输入，以便与 G08 直接比较。仍属于均匀半椭球/等效球近似，没有获得空间内核或靶面间隙预测。
