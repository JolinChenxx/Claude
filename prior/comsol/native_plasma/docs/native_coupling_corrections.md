# 原生 Plasma 与气相/导体耦合中的已核实修正

以下结论来自 COMSOL 6.4 当前模型的实际 Equation View 和保存解；不能把变量名的字面含义当作方程定义。

## 1. 重粒子扩散的焓与电流

本模型有限元原生变量 `plas.tfluxr_wCu` 的实际定义为

`plas.cfluxr_wCu + plas.mfluxr_wCu + plas.Tflux_r_wCu`。

其中 `Tflux_r` 是热扩散项，普通浓度扩散没有包括在这个输出变量中。物种弱式实际使用 `plas.jr_wCu`，它由普通扩散、热扩散、电迁移等项叠加得到。P60 保存解上，`tflux-cflux-j` 的积分绝对值与中性铜 `j` 的积分绝对值相同，直接证实原能量耦合漏掉普通扩散焓。

P61 在原生物种方程保持求解的基础上，用 `cflux+j` 重建两方向的总质量通量，供气相扩散焓、电流、边界通量审计共同使用。开启原生 `MixtureDiffusionCorrection`，使物种扩散与重心系总质量守恒一致。脚本：`src/NativeFluxConsistency.java`。

## 2. 电子壁通量必须与导体电流采用一致积分

P60 在 84.6 ns：

| 数量 | 数值 |
|---|---:|
| 壁净电子注入率，二阶积分 | 9.9972e12 s^-1 |
| 同一表达式，六阶积分 | 4.09821e13 s^-1 |
| 同一表达式，十六阶积分 | 4.09830e13 s^-1 |
| 体电子变化率 | 9.3242e12 s^-1 |
| 体净电子反应源 | -6.709e11 s^-1 |

原生电子壁弱式默认二阶积分，而独立导体电流采用不同积分阶数。热发射与回流两个大通量相减时，积分差异形成很大的净电荷误差。体反应源的电子/离子净电荷严格对应，不能通过修改反应率消除这一误差。

P61 用二阶负弱项精确抵消原生壁贡献，再用八阶正弱项加入同一壁定律；导体电流的面积积分也使用八阶。该修正改变积分规则，不改变 Richardson 发射与电子吸收定律。`wallConv` 与导体反力校正同样采用八阶。源：`FluxIdentityAudit.java`、`ChargeRateAudit.java` 的保存解核算。

## 3. 轴对称弱导体约束的乘子度量

原生 Poisson 弱式含 `2*pi*r`，而 MetalContact 的弱约束反力是

`+V_lm*test(V) - V_lm*test(V0)`。

因此 `V_lm` 是负的每弧长电荷量，不能直接把它按轴对称表面积积分。实际金属电荷为 `-integral_line(V_lm)`。P49 保存解确认，该量与从电场求得的金属电荷面积积分一致。

移动曲线的电荷输运使用

`d(V_lm,TIME) + V_lm*(dtang(meshVr,r)+dtang(meshVz,z))`。

对其作弧长积分，再加面积积分的粒子电流 `Iwall`，得到无外加电流导体的总电流方程。同时取消 `V0` 方程中额外的约束反力，保留电势连续性约束。P59/P60 已验证这一修正后，独立 `qmetal` 与乘子弧长积分一致。

脚本：`src/ConservativeMetalContact.java`；审计：`src/ElectrodeAudit.java`。

## 使用限制

这些修正解决已证实的实现问题，不等同于 S4 实验验证。P61 仍需保存解检查铜质量、电荷、总能量、温度及光子量级。此前 P49/P60 图仅作诊断，不用于宣称实验吻合。
