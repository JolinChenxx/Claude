# 原生双区等离子体诊断

G21–G22 在模型时间 103 ns 的近靶控制体中得到约 48.39 W 的激光吸收，同刻 G16 均匀膨胀模型为 0.293 W。这里改变的是空间平均闭合，并未调整碰撞率或电子种子；该敏感性支持进一步检查近靶高密度区。

G30 从初态重新建立两个 COMSOL 原生 Plasma 组件：半径 11 μm 的固定近靶半球，以及外侧膨胀半球壳。两区初始密度、温度和电子种子相同；只有一个铜靶传热组件。两区均独立求解原生反应与电子能量，以各自实际组分和气温闭合压力和内能。扫入空气暂时沿用 G16 的独立惯性薄壳。

界面采用可双向流动的等熵喷口近似，压力由两区反馈决定。物种随供体质量分数流动，电子携带供体电子焓，完整能量通量包括平动、化学和电子焓。相同界面通量在两个守恒方程中符号相反。外气相使用球壳均匀密度、同胚径向速度的动能系数 κ=3(R⁵−a⁵)/[5R²(R³−a³)]；其变化对应的动能项也进入总能量账本。这个速度闭合仍是低阶矩近似，不代表解析了喷流入口速度分布。

激光先穿过外区，再进入内区和铜面，铜面反射后反向穿过两区。覆盖功率由铜面网格积分，激光吸收与高能级光电离使用同一局部平均强度。总体账本只把靶面和两区的吸收记作外部输入；区间焓流不重复计入总输入。

仍有明确限制：固定近靶尺度、均匀半球壳、无显式鞘层、无离面亮核的位置预测；高温铜物性仍继承旧闭合。动力学中的谱线逃逸率分别按每个区估算，未加入两区间的辐射再吸收及其能量交换。因此本工况首先用于诊断供料、局部吸收和膨胀，不能直接称为完成二维实验验证。结构和方程改变后均从初态重算，不复用不兼容的旧解。
