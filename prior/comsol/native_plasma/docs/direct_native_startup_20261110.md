# 近零电子反应单元的直接初始化

18:37，HC442 在 96.5 ns 保存后，冷空气反应批次无法找到一致初值。相同单元此前也使小批次 R434 失败。不是通过增加初始电子来处理。

原有负氧离子脱附反应仍有电子产生源。采用现有反应率，初始源为

\[
S_e=3\times10^{-16}n_{O^-}n_O+3.3\times10^{-16}n_{O_2^-}n_O.
\]

单位为 m⁻³ s⁻¹。输入温度、组分和总能量已经按同一代数能量关系构造；R436 关闭额外的一致初始化过程，并将首个 BDF 步设为

\[
\Delta t_0=\min(\Delta t/100,\,0.1\min_{S_e>0}n_e/S_e).
\]

极低自由电子数会给出极短首步；这仅用于数值起步，之后由求解器放大时间步，不表示模型具有相应尺度的物理分辨能力。反应系数、输入组分和电子源均未改变。R436 实际未启用 localEnergyScale，已纠正其配置记录。

相同失败输入成功完成 0.25 ns：质量最大相对残差 2.98×10⁻¹⁶，电荷变化相对带电粒子数残差 1.70×10⁻¹⁴，总能量最大相对残差 3.72×10⁻¹²。另与 R427 已成功的相同输入比较，电子密度、电子能量、辐射损失和可见发射率的最大峰值归一化差异分别为 0.0664%、0.0229%、0.0107%、0.0113%。本次小批次耗时 19.35 s。

审计原始结果在 `results/R436_operator/startup_conservation.json`、`comparison.json`，保存的原生局部反应模型为 `native_operator_local_energy_air96p5.mph`。该 MPH 是独立局部反应单元，不能当作完整空间羽流模型。

HC445 从 HC442 的真实 96.5 ns 保存态续接，使用同一材料方程和反应率，并启用上述小批次初始化。随后排队 HC446 至 835 ns、HC447 至 1000 ns。是否已完成以各目录的 status.json 和真实帧为准。
