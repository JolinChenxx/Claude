## 2. LTE 基线的实际物理模型

二维轴对称r–z，气相域r=0–2 mm、z=0–3 mm；下方100 μm铜层（计算截断厚度，不是论文整块样品厚度）。守恒未知量为混合气密度、r/z动量、总能量和铜组分；轴线对称，外侧环境/出流，底面与靶材蒸发/换热耦合。全部实际边界选区及表达式保存在导出Java，历史曾把边编号1误作底面，最终已改真实底面2，旧失败结果不作主例。

气相压强、温度、电子及离子数由 `lte_grid.txt` 插值表决定（Cu/空气LTE单温），不是常γ理想气体。气相可压缩保守PDE、靶材焓法热传导与熔化。Clausius–Clapeyron饱和蒸气压结合背压得到净蒸发/回凝；热/质量/焓与气相耦合。表面退缩用守恒ALE（J和实际物理坐标），不能用固定界面喷气模型代替。

1064 nm、高斯60 ns FWHM、峰值数值时间120 ns、400 μJ、1/e²半径11 μm。双程气相光吸收和靶面反射；表面吸收率固定0.1，未从实验灰度反演。已算总吸收约40.02 μJ，其中羽流约0.01868 μJ、靶约40 μJ。**并非把400 μJ全部注入气相。** 该气相吸收与新PLAN希望的强屏蔽量级明显不同，应保留这一失败证据。

空间离散：COMSOL一次元流体/热/光学、二次位移，BDF最高1阶、rtol=.002、基线最大步.5 ns。B64A 8143单元，G64AC2 14299单元（网格尺寸×.75），G264R1C5 25009单元（×.5625），T64AC2同基线网格/最大步.25 ns；均613个唯一保存时刻至2120 ns。Newton迭代策略曾分段切换并官方保存/合并真实历史，不插值制造流体时间段。

**耗散不能误称成可靠物理粘性。** `Dnum=nuFactor*h*(speed+csBound)` 等数值守恒稳定项用于质量/组分/动量/能量，最终nuFactor=2；低铜梯度前沿另有nuLocal=1局部项。另有气体导热、靶面0.5 μm换热长度闭合；无完整实测粘性/多组分扩散系数模型。具体输运表达式在Java中。模型常量和稳定项的未确认来源是unknown，不自动赋予文献来源。

辐射方面：流体基线保留原有LTE/free-free闭合；后处理加入NIST可见谱线/吸收。没有把后处理全部可见辐射项自洽加入每个流体时间步。对已建模380–780 nm谱线+free-free，全FE域未衰减发射上界0.0001463 μJ，占吸收0.0003656%，未触发原流程5%反馈门槛。这个上界**不涵盖遗漏的UV/IR、自由束缚或分子辐射**。

## 3. LTE 发光、相机及拟合

`radiation_s4.py` 使用保存的真实LTE场、NIST Cu I/II、N I/II、O I/II有效谱线及free-free。Boltzmann上态布居，`jν=hν A n_u φν/(4π)`，`αν=jν/Bν(T)`；自然+Doppler近似Voigt，含径向流速的视线Doppler位移，未拟合Stark宽度。柱坐标视线逐段形式解；ALE坐标先反变换到真实空间，不直接将铜质量或温度画成发光。

主通带475–525 nm，敏感性490–510/450–550 nm；10 ns门对真实保存时刻的线性辐亮度精确积分。400 μm标尺按36像素，物方11.111 μm/px；与PLUTO按37px有标尺端点差异，不能混用曲线。PSF=1px FWHM（另试0/2px），统一背景2，统一线性增益后8位饱和、jet显示。实验由PDF压缩伪彩反解，不是原始CCD；轮廓阈值27，另100/220，共同3×3开闭和最大连通域；保存半径、面积、体积、均灰度等CSV。

**确实发生的拟合：** 只用实验0–80 ns的7帧排序像素灰度分布，搜索固定时移60–120 ns/步2 ns和一个全局增益。最终时移118 ns、gain=4.420016e67；背景按角落估计2；150–740 ns 22帧留出。没有逐帧增益，但该极大增益无物理光子依据，不能称为成功的相机标定。验证工况冻结主例相机参数，不另拟合。

## 5. 基线对照结果、数值问题

基线最高温约6981 K、峰电子密度2.283e24 m⁻³、气相铜峰值1.871 ng、最大表面退缩2.054 μm。终点铜残差-0.01061%、能量-0.02896%；守恒检查通过不等于成像机制正确。

| 指标 | 出版图重建 | 冻结响应LTE | 结论 |
|---|---|---|---|
| 半径峰值 | 322.2 μm，180 ns | 455.6 μm，250 ns | 幅值/时刻不符 |
| 面积峰值 | .3031 mm²，260 ns | .8099 mm²，580 ns | 不符 |
| 平均灰度峰值 |119.5，60 ns |255，630 ns | 不符 |
| 阈值27最后可见采样 |630 ns |740 ns | 模型灰度消退太慢 |

然而**物理LTE辐射其实消失太快**：覆盖所有60–120ns允许时移的全域、全方向、10ns可见光子上界，在实验260ns最多9.242e-6光子、400ns最多6.213e-13光子。极大增益把远低于单光子的平滑尾部放大为亮图，解释了“灰度太亮”和“真实LTE发射不足”为什么同时存在。约99.93%的模拟可见掩模像素低于1个理想收集光子。不能只降低增益追拟合解决物理缺失。

时间步减半通过既定S4四项10%目标；网格未通过。基线→.75网格，半径/面积/净灰度最大变化14.29%/23.91%/20.21%，饱和前物理亮度19.78%；.75→.5625仍为10.34%/17.5%/17.76%，物理亮度8.23%，综合仍失败。追加网格的局部速度曲线差异很大；守恒通过不能代替网格独立性。
